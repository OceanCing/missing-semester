## 4. Shell

### 4.1 命令结构

Shell 命令的基本形式：

```text
命令 [选项] [参数]
```

常见示例：

| 命令 | 选项 | 参数 | 含义 |
| --- | --- | --- | --- |
| `ls` | `-la` | `~/project` | 列出目录中的全部内容 |
| `rm` | `-r` | `project` | 递归删除目录及其内容 |
| `man` | — | `命令` | 查看命令的说明 |

### 4.2 条件比较

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `-lt` | 小于 | `[ "$a" -lt "$b" ]` |
| `-le` | 小于或等于 | `[ "$a" -le "$b" ]` |
| `-gt` | 大于 | `[ "$a" -gt "$b" ]` |
| `-ge` | 大于或等于 | `[ "$a" -ge "$b" ]` |
| `-eq` | 等于 | `[ "$a" -eq "$b" ]` |
| `-ne` | 不等于 | `[ "$a" -ne "$b" ]` |

### 4.3 输出与环境变量

```bash
echo "文本内容"
echo -e "hello\nworld"

printenv
echo "$PATH"
```

### 4.4 目录与路径

| 命令 | 作用 |
| --- | --- |
| `cd ~` | 切换到用户家目录 |
| `cd -` | 切换到上一次所在的目录 |
| `cd .` | 保持当前目录 |
| `cd ..` | 切换到上一级目录 |
| `pwd` | 显示当前逻辑路径，可能保留软链接名 |
| `pwd -P` | 显示解析软链接后的实际路径 |
| `cd -P 软链接名` | 进入软链接目标的实际目录 |

### 4.5 文件与目录操作

| 命令 | 作用 |
| --- | --- |
| `ls` | 显示目录内容 |
| `touch` | 创建空文件或更新时间戳 |
| `mkdir -p` | 创建目录，并按需创建父目录 |
| `rmdir` | 删除空目录 |
| `cp 源 目标` | 复制文件 |
| `cp -r 源目录 目标目录` | 递归复制整个目录 |
| `mv` | 移动或重命名文件 |
| `rm -r` | 递归删除目录及其内容，使用时需谨慎 |

### 4.6 查看与过滤文件内容

```bash
head 文件名
head -n 5 文件名

tail 文件名
tail -n 5 文件名
tail -f 文件名

# 实时过滤新增内容
tail -f 文件名 | grep "关键词"

cat 文件名
cat -n 文件名

less 文件名
more 文件名
```

`cat -n` 会显示所有行号，包括空行。

使用 `more` 浏览文件时：

| 操作 | 作用 |
| --- | --- |
| 空格 | 翻页 |
| `Enter` | 下一行 |
| `b` | 返回上一页 |

### 4.7 重定向、管道与命令连接

| 写法 | 作用 |
| --- | --- |
| `命令 > 文件` | 覆盖写入文件 |
| `命令 >> 文件` | 追加写入文件 |
| `命令1 \| 命令2` | 将前一命令的输出交给后一命令 |
| `命令1 && 命令2` | 前一命令成功后才执行后一命令 |

### 4.8 硬链接与软链接

创建链接：

```bash
ln 原文件 硬链接名
ln -s 原文件或目录 软链接名
```

硬链接与原文件使用同一个 inode，并指向同一份文件数据：

```mermaid
graph LR
    A["文件名 a"] --> I["inode X"]
    B["文件名 b"] --> I
    I --> D["同一份文件数据 code"]
```

删除 `a` 不会影响通过 `b` 访问文件；删除 `b` 也不会影响 `a`。文件数据只有在最后一个硬链接被删除时才会释放。

软链接拥有独立的 inode，其中保存的是目标文件的路径：

```mermaid
graph LR
    A["目标文件 a<br/>inode X"] --> D["文件数据 code"]
    B["软链接 b<br/>inode Y"] -. 保存目标路径/地址 .-> A
```

删除目标文件 `a` 后，软链接 `b` 仍然存在，但会变成无法访问的失效链接；删除软链接 `b` 则不会影响目标文件 `a`。

删除软链接时，直接删除链接本身即可：

```bash
rm 软链接名
```

不要写成 `rm -r 软链接名/`。末尾的 `/` 可能使命令跟随软链接处理目标目录，从而导致误删。

### 4.9 快捷键与历史记录

| 快捷键或命令 | 作用 |
| --- | --- |
| `Ctrl+C` | 终止当前进程 |
| `Ctrl+L` | 清屏 |
| `Tab` | 提示并补全命令 |
| `↑` / `↓` | 查找使用过的命令 |
| `history` | 显示全部历史记录 |
| `history 10` | 显示 10 条命令记录 |
| `history -c` | 删除历史记录 |
