# OpenCV 05：两根灯条配对

前几课筛选单个红色细长区域。本课把候选灯条两两组合，比较长度、位置和方向差，得到装甲板候选区域。使用合成图观察配对规则，尚未接入相机或识别装甲板上的数字。

## 实验记录

放宽 `Max pair diff` 后，观察到 `Lights` 没变，`Accepted pairs` 从 1 变成 2。日志中四根灯条始终通过单根筛选、两组始终通过长度与位置条件；变化只发生在最后的方向差筛选。默认 10° 时只有同向倾斜的 A 组通过；放宽到 55° 后，方向相反的 B 组也通过。

实际输出中，A 组方向差为 0°，B 组约为 50.0338°。放宽门槛增加的是符合当前规则的候选组合，并不代表目标识别一定更准确。这张合成图用于说明方向条件过松时会选入原本希望排除的组合。

## 从单根角度到两根方向差

单根灯条偏离竖直方向 25°，可能左倾，也可能右倾。只保留角度大小，会把不同方向记成同一个值。

本课把长轴统一取朝上的方向，再定义左倾为负、右倾为正：

| 两根灯条的方向 | 两根之间的方向差 |
| --- | --- |
| 右倾 25°、右倾 25° | 约 0° |
| 左倾 25°、右倾 25° | 约 50° |

图像坐标仍然是 x 向右、y 向下。[light_pairing.hpp](src/light_pairing.hpp) 保留上一课的长轴向量，通过点积、叉积计算两条无向长轴的较小夹角。界面用带正负号的倾角帮助观察，计算方向差时不依赖显示文本，也不把无向长轴的正反误当成 180° 差异。

这些角度是像素轮廓的测量值，可能与生成图像时设定的角度略有差异。

## 本课的配对规则

单根条件固定为 HSV 红色、面积至少 200、长短边比至少 3.0、偏离竖直不超过 35°，让四根红条都成为灯条候选。

对任意两根候选先比较长度和位置。设平均长度为两根长边长度的平均值：

```text
较短灯条长度 / 较长灯条长度 >= 0.7
两根中心的竖直距离 / 平均长度 <= 0.3
0.5 <= 两根中心的水平距离 / 平均长度 <= 1.5
```

以上条件固定，避免左组与远处右组随意组合。再要求：

```text
两根长轴的方向差 <= Max pair diff
```

本课只调整最后一个条件。用长度归一化距离，可以避免把配对距离直接固定成某个像素数。上述范围用于这张教学图，实际目标的透视、姿态和规格需要进一步考虑。当前输出所有满足条件的候选配对，未进行多组配对间的冲突处理。

## 配对中心的图像坐标

程序用两根灯条中心的中点估计候选区域在图像中的中心，对应[绘制代码](src/main.cpp)：

```text
u_center = (u_left + u_right) / 2
v_center = (v_left + v_right) / 2
```

这里的 u 对应图像 x 坐标，向右增大；v 对应图像 y 坐标，向下增大，原点在左上角。它们的单位是像素。

A 组两根灯条中心实测约为 `(99.5, 179.5)`、`(199.5, 179.5)`，中点约为 `(149.5, 179.5)`，即画面中的青色中心圆点。这是二维图像位置的估计，不能直接作为目标在真实空间中的米制坐标。

中心位置不变不代表目标在空间中没有移动。相机固定、不变焦且目标保持正对相机时，若图中灯条越来越短，可以判断目标在远离；尺寸与深度的关系见[相机成像入门](../06-camera-model/README.md)。
