# 神经网络笔记

## 模型与 CNN

- 网络用参数（权重、偏置）将输入映射到输出；训练通过数据调整参数，推理使用已有参数计算结果。
- CNN 中，卷积提取局部模式，ReLU 引入非线性，池化降低空间尺寸，全连接层输出类别分数。
- 本例输入为 float32、NCHW：`[批量,通道,高,宽]=[1,1,32,32]`；输出为 11 类 logits，即 softmax 前的原始分数。

## 训练与更新

```python
optimizer.zero_grad()          # 清除上一批梯度
logits = model(images)         # 前向计算
loss = loss_fn(logits, labels) # 衡量预测与标签的差异
loss.backward()               # 计算梯度
optimizer.step()              # 更新参数
```

- 交叉熵惩罚真实类别概率过低的预测。PyTorch 的 `CrossEntropyLoss` 直接接收 logits，无须先手动 softmax。
- `backward()` 不更新权重，学习率在优化器更新时使用。基本 SGD 为 `参数 -= 学习率 × 梯度`；Adam 还利用梯度统计量调整更新。
- batch 是一批样本，epoch 是遍历训练集一遍，step 是一次参数更新。常规每批更新一次时，每轮 step 数为 `ceil(样本数 / batch_size)`。

## 数据与泛化

- 训练集更新参数，验证集调参和选权重，测试集用于最终评价。按视频、场次等来源分组，避免同源近似样本跨集；精确去重与近似重复还需单独检查。
- 训练表现仍差时，先检查输入、标签、模型和训练是否充分；训练好、验证差提示泛化不足，还要结合数据分布分析。
- 增加数据覆盖、合理增强、正则化和早停等方法按验证结果选择。增强后的样本必须保持标签含义，且不能代替真实数据覆盖。
- 最佳权重按预先确定的验证指标保存；最高准确率、最低损失和最后一轮可能对应不同权重。

## 推理与评价

- `model.eval()` 切换 Dropout、BatchNorm 等层的行为；`torch.no_grad()` 关闭作用域内的求导记录。常规推理配合使用。
- 准确率看预测第一名是否正确，交叉熵看真实类别的概率，两者可能不同步。混淆矩阵按真实类别和预测类别统计，帮助定位具体误检、漏识别与类别差异。
- softmax 将 logits 转成已知类别间和为 1 的相对分数，最大值不能直接当成经过校准的实际正确概率。
- 提高接受门槛会拒绝更多结果，也可能漏掉正常目标；陌生输入仍可能高分。negative 是需要训练的负类，不会自动覆盖所有未知内容。

## 部署与视觉流程

- 两端输入约定要一致：ROI、通道、尺寸、插值、数据类型、布局、归一化与明暗关系。窗口显示相同，不代表网络收到的张量相同。
- ONNX 保存计算图和参数；算子及版本需要部署库支持。模型外的图像处理、softmax 和阈值仍要保持一致。
- 固定同一图片与权重，比较两端完整 logits 及数值误差；再核对文件 hash、类别 ID→标签表和后处理。数值一致不代表识别精度合格。
- 检测无候选、分类拒识、位姿无效分别表示不同状态。ROS 输出保留输入时间戳和坐标系标识，下游先检查有效标志，丢失时清空结果。
