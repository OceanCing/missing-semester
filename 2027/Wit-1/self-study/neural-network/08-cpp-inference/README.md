# 08 C++ 推理与预处理故障

C++ OpenCV DNN 加载第 07 节生成的同一模型包。

## 数值对齐

终端实际输出：

```text
C++ PARITY cases=12 max_difference=1.14441e-05
```

输出文件确认 OpenCV 为 **4.2.0**，12 张固定输入的 logits 最大差约 **0.00001144**，低于门槛 **0.001**。第 07 节 Python OpenCV 的对应值约为 0.00000763，两次都在门槛内。

## 正常与反色对照

| 送入网络的预处理 | 窗口预测 | 窗口分数 |
| --- | --- | --- |
| normal | 7 | 1.00 |
| invert | negative | 0.99 |

模型与原始图片不变，只增加 `--preprocess=invert`。窗口仍展示原图，反色只发生在进入网络之前，因此单看显示图片不能确认实际张量。

日志中反色的更完整分数约为 **0.999981**，类别 ID 为 10，`accepted=0`。窗口截取较短的分数字符串，记录时区分显示与日志精度。负类分数再高，仍会按接受规则拒绝。

这组对照说明，部署预处理不一致足以改变输出，即使输出依然高分。排查时应先核对实际张量、权重和类别约定，再解释模型效果。
