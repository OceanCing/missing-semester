# 03 ROI 到模型输入

使用预置参考模型，将带灯条的 160×80 数字 7 ROI 裁出中央一半宽度，再转换为网络输入。

```text
透视 ROI → 中央数字区域 → 灰度 → resize(32,32)
         → float32 / 255 → [N,C,H,W] → CNN
```

单张灰度图的形状为 `[1,1,32,32]`，依次表示批量、通道、高、宽。本模型使用白字深色背景，仅做 `/255`，没有额外减均值或除标准差。

## 实验记录

| 模式 | 输入范围 | 预测 | 最大 softmax 分数 |
| --- | --- | --- | --- |
| normal | 0～约 0.9216 | 7 | 1.0 |
| raw，漏掉归一化 | 0～235 | 7 | 1.0 |
| invert，反色后归一化 | 约 0.0784～1 | negative | 1.0 |

终端读到 normal 最大值 `0.9215686`、raw 最大值 `235.0`，对应 `235 / 255 ≈ 0.9215686`；两组形状相同。

raw 仍预测正确且分数高，输入尺度却已偏离训练约定。invert 虽仍在 0～1 内，明暗关系改变后输出变成负类。因此要同时核对裁剪、通道、尺寸、类型和数值变换。

显示时 normal 被乘回 255，raw 直接使用像素值，所以窗口中两张图可能相同；显示图相似不代表网络实际接收的张量相同。
