## AI 协助与自己需要做的事

| 内容 | 学习时的分工 |
| --- | --- |
| 配置环境、创建包、准备构建文件和示例 | 由 AI 协助完成，自己理解用途、文件分工和关键路径 |
| 解释代码、整理命令、编写检查脚本 | 可以用 AI 辅助，但要对照实际运行结果判断 |
| 运行示例、调参数和连接话题 | 结合窗口、消息与运行记录观察结果，对照代码解释变化 |
| 遇到错误 | 保留现象和完整报错，让 AI 协助定位和修复，自己理解关键改动并核对结果 |
| 后续接触硬件与视觉 | 相机安装、采集标定图像、检查真实效果等需要实际操作，AI 可辅助分析和处理数据 |

目前重点是读懂关键逻辑，能解释程序输入、输出和参数的作用，提出问题并验证结果。环境配置、构建和具体报错排查可以持续借助 AI。
