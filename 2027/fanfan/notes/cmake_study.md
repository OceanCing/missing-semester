# 第二课 Cmake与Catkin 学习笔记
这节课的信息量有点大，主要是讲怎么把代码编译出来，还有 Agent 软件。
## 一、 编译到底是怎么回事
以前觉得写代码点个运行就行了，今天才知道底层这么麻烦，一个源码要经过预处理、编译、汇编，最后才变成机器码
课上看到那个 `g++` 的演示图，如果项目文件多，觉得把它们分别编译成 `.o` 文件，然后再“链接”起来。要是少链接了一个，程序就会报错，但是文件一多，手动敲太累了，就用 `Makefile`，但是换个系统 `Makefile` 又不行了，这就要用 **CMake**。CMake 能针对不同的系统，自动生成对应的 `Makefile`
## 二、 Catkin 是什么
我们搞机器人用 ROS，而 ROS 用的就是基于 CMake 扩展出来的 **Catkin**PPT 里那个图挺清楚的，建好工作空间后，有三个大文件夹：
- `src`：我们放源码的地方
- `build`：中间文件，老师说不用管
- `devel`：编译出来的可执行文件都在这
- `catkin_create_pkg` ：建功能包，里面必须要有 `CMakeLists.txt` 和 `package.xml`
## 三、 补充资料和读后感
- **ROS Wiki 和 菜鸟教程**：全是干货，纯查手册用的，看了个大概，知道怎么建包写 CMakeLists 了
- **知乎那篇**：大佬写得挺通俗的，理清了工作空间的逻辑
- **《The Emperor Has No Clothes》**：大概意思是说，现在大家太迷信 AI 了，就像皇帝的新装， AI 也就是个概率补全模型，有时候会“一本正经地胡说八道”要是完全依赖它，自己不动脑子，迟早要翻车，所以我们还是要在有真本事的基础上，使用ai，才知道他是对还是错
## 四、 关于大模型和 Agent 的真实体验
今天下午我刚好去体验了一下那个能直接操作电脑的 Agent 软件（DeepSeek Harness），它确实能自己建文件、自己改代码，看着挺酷的，但是，它也是真的费token，这个吃白饭的大肥鱼！！！要是指令下得不清楚，它可能乱删文件或者瞎写。这让我深刻意识到，**AI 只能是辅助我们的工具**
以后写代码或者做题，我还是得先自己想，实在卡住了再去问ai，就算问ai，也是要了解递增逻辑，为什么这样，而不是这样，直接抄，这样啥也不会
