- ***SSH密钥***  
  一、SSH密钥是什么
    SSH密钥是一对用于身份验证的加密文件，包含私钥和公钥两部分
    - 私钥：留在本地电脑，绝不能泄漏或分分享。它用于向服务器证明“你是你”。
    - 公钥：可以安全地交给GitHub等平台。GitHub保存个人的公钥后，当个人通过SSH操作时，会用公钥来验证个人是否持有对于的私钥。
    - **总的来说**：公钥在GitHub,私钥在个人的电脑，两者匹配即通过验证，从而免去每次输入账号密码的麻烦。

  - ls -al -/.ssh

## C/C++ 编程基础笔记

### 一、 基础语法与输入输出

#### 1. 占位符与 printf
- `printf()` 用于在文本中指定占位符。
- **核心规则**：`n` 个占位符，对应 `n` 个参数，必须一一匹配。
- 示例：`printf("there are %d apples\n", 3);`

**常用占位符及对应类型：**
| 占位符      | 数据类型             | 说明                        |
| :---------- | :------------------- | :-------------------------- |
| `%c`        | `char`               | 字符                        |
| `%d` / `%i` | `int`                | 十进制整数                  |
| `%hd`       | `short int`          | 短整型                      |
| `%ld`       | `long int`           | 长整型                      |
| `%lld`      | `long long int`      | 超长整型                    |
| `%u`        | `unsigned int`       | 无符号整数                  |
| `%hu`       | `unsigned short int` | 无符号短整型                |
| `%f`        | `float`              | 单精度浮点数                |
| `%lf`       | `double`             | 双精度浮点数                |
| `%Lf`       | `long double`        | 长双精度浮点数              |
| `%p`        | 指针                 | 打印地址                    |
| `%s`        | 字符串               | 字符串                      |
| `%o`        | 整数                 | 八进制                      |
| `%x`        | 整数                 | 十六进制                    |
| `%e`        | 科学计数法           | 浮点数科学计数法            |
| `%zu`       | `size_t`             | 尺寸类型 (如 sizeof 的结果) |

- **精度与宽度控制**：
  - `%5d`：右对齐，占满 5 位。
  - `%-5d`：左对齐，占满 5 位。
  - `%f`：默认输出 6 位小数。
  - `%12f`：最少占 12 位。
  - `%+d`：强制显示正负号。
  - `%.2f`：保留小数点后两位。

#### 2. 浮点型与字符型
- `float fm = 1.11f;` （加 `f` 后缀转换为单精度）。
- `double dm = 2.22;` （默认为双精度，格式符为 `%lf`）。
- `float` 有效位数只有 6~7 位；`double` 为 15~16 位。

#### 3. 输入处理 (scanf)
- **注意**：`scanf` 接收变量地址，需加 `&`，如 `scanf_s("%d", &num);`。
- **规则**：
  1. 只接受变量地址（名称）。
  2. 遇到空格、Tab、回车会被忽略（作为分隔符）。
  3. `scanf` 格式化字符串中不能以 `\n` 结尾。
  4. 格式化字符串中除了格式化占位符，若还有别的字符，则必须原样输入。
  5. 接收多个非字符型数据时，可通过空格、Tab、回车作为分隔符。

#### 4. 字符输入输出
- `putchar(ch);` // 输出一个字符
- `ch = getchar();` // 获取一个字符
- 加减乘除之间运算一定是整数（若均为整数）。

#### 5. 内存地址与大小写转换
- 内存地址：**从大到小**分配。
- 大小写转换：

### 二、 运算符与表达式

#### 1. 赋值与算术运算符

- 复合赋值：+=、-=、*=、/=、%= 等。右结合性，优先级低于算术运算符。
- 取模 %：操作数必须是整数。

#### 2. 自增自减运算符 (++, --)

- i++ / i--：后置，先参与其他计算，再自增/减。
- ++i / --i：前置，先自增/减，再参与计算。
- 注意：
  1. 只能用于变量，不能用于常量和表达式。
  2. 企业开发中，自增自减运算符最好单独出现，不要放在表达式中。
  3. C 语言中没有规定同一个表达式中同一个变量同时被自增/减两次的运算规则。

#### 3. sizeof 与逗号运算符

- sizeof：计算字节数，优先级高于算术运算符。
- 逗号运算符：右结合性。同时定义多个变量；返回结果是最后一个表达式的结果。

#### 4. 关系与逻辑运算符

- 关系运算符：> < >= <= == !=。非 0 为真，0 为假。优先级：前四个高于 == 和 !=，左结合性。
- 逻辑运算符：
  - && (逻辑与)：一假则假，左结合性。逻辑短路现象：有假不再运行后面。
  - || (逻辑或)：一真则真，左结合性。逻辑短路现象：有真不再运行后面。
  - ! (逻辑非)：真变假，假变真，右结合性。

#### 5. 三目运算符

- 格式：条件表达式 ? 结果A : 结果B;
- 注意：? : 是一个整体，不能单独出现。

#### 6. 类型转换

- 自动类型转换：编译器自动将小类型转为大类型（如 int 转 double）。如 double value = num;
- 强制类型转换：(类型)变量，如 (double)num;。注意：类型转换不会影响原有变量。

### 三、 流程控制结构

#### 1. 选择结构 (if)

- 单分支：if(条件表达式) { 代码 }
- 双分支：if(条件表达式) { ... } else { ... }（只有一个会被执行）
- 多分支：if... else if... else（从上至下依次判断，大括号中只有一个会被执行且只执行一次）。
- 避坑指南：
  1. if 后 {} 可省略，但仅控制紧随其后的一条语句。企业开发中坚决不要省略 {}。
  2. 如果省略了 {}，不能在紧跟其后的位置定义新的变量。
  3. else 总是与最近的未匹配的 if 结合。
  4. C 语言中非 0 即真。
  5. 判断相等时，常量写前面（如 0 == a），防止漏写等号报错。
  6. 一般不要嵌套超过三层。

#### 2. switch 选择结构

- 格式：
  ```c
  switch(表达式) {
      case 常量表达式1:
          代码;
          break;
      case 常量表达式2:
          代码;
          break;
      default:
          代码;
          break;
  }
  ```
- 特点：多路选择，只能针对整型或字符型（不能是浮点数），只匹配具体值，不适合范围判断。
- 注意：
  1. case 后的值不能重复。
  2. case 后面不能定义新变量（如必须定义，需加 {}）。
  3. break 不能省略，否则会发生 case 穿透；default 位置随意，但通常放最后（放最后时 break 可省略，但一般不建议省）。

- if vs switch：if...else if 针对范围的多路选择；switch 针对点的多路选择。
  


#### 3. 循环结构

- while：while(条件表达式) { 循环体 }。适合不知道循环次数的情况。
  - 任何数值都有真假性；最简死循环：while(1);
  - 单条语句时大括号可省略，但不能定义变量。
  - ; 是空语句。
- do-while：先执行一次，再判断。无论如何都要先执行一次。
  - 格式：do { ... } while(条件); （注意分号不能丢）
- for：for(初始化; 条件; 循环后操作) { 循环体 }。适合知道循环次数的情况（能用就用）。
  - 执行顺序：初始化 -> 条件 -> 循环体 -> 循环后操作 -> 条件...
  - 最简死循环：for( ; ; );
  - 作用域：for 循环 {} 中定义的变量，不能在 () 中访问。{} 中可定义与 () 中同名的变量。

#### 4. 跳转语句

- break：立即跳出当前所在的 switch 或一层循环。下面不能有语句。
- continue：跳过本次循环剩余部分，进入下一次循环。离开循环结构存在无意义，下面不能有语句。
- goto：跳转到指定标签（如 loop:），慎用。可往前/后跳，只能在同一函数内跳转。
- return：结束当前函数。

#### 5. 循环嵌套

- 一般不超过三层。
- 规律：外循环控制行数，内循环控制列数。总执行次数 = 外层次数 * 内层次数。
- 经验：遇多行多列需求想到循环嵌套；化繁为简。
- 图形打印技巧：内循环条件表达式等于外循环变量（打印三角形）；或内循环初始化等于外循环变量（打印倒三角）。

### 四、 函数与进制

#### 1. 函数基础

- 好处：封装常用功能，减少冗余代码，需求变更时修改代码变少。
- 格式：返回值类型 函数名(形参列表) { 函数体 }
- 步骤：起有意义名称(标识符规则) -> 确定形参列表 -> 编写逻辑 -> 确定返回值类型。
- 注意点：
  1. 函数名不能相同。
  2. 函数中不能定义函数。
  3. 函数中不能定义和形参同名的变量。
  4. 形参不影响实参（基本数据类型）。
  5. 如果没有返回值，返回值类型推荐写 void。
  6. C语言中任意类型都可作为返回值类型。

#### 2. 函数声明

- 如果函数定义写在调用之后，必须在调用前进行声明。
- 格式：返回值类型 函数名(形参类型);（参数名可省略）。
- 注意：声明可以重复，定义不可重复，调用前声明即可。

#### 3. 递归函数

- 函数自己调用自己。每次调用要开辟栈空间，性能比循环差。作用是实现循环相关功能。

#### 4. 进制与补码

- 常见进制：十进制、八进制（前缀 0）、十六进制（前缀 0x）。
- 二进制：C语言中没有提供以二进制输出的占位符。
- 原码/反码/补码：
  - 正数：原码 = 反码 = 补码。
  - 负数：最高位（符号位）为 1；反码 = 原码除符号位外各位取反；补码 = 反码 + 1。
- 计算机中存储和参与运算的数据都是补码。正数补码转为十进制直接算；负数计算得出结果后，先转为原码，再转十进制。

### 五、 位运算与数组

#### 1. 位运算符

用于对整型数据进行二进制运算。

- & 按位与：一假则假（同1为1）。应用：任何数与1按位与，结果不变；与0按位与结果为0。
- | 按位或：一真则真（有1为1）。应用：按位或上0，结果等于自己。
-  ^ 按位异或：相同为0，不同为1。应用：按位异或上另外两个数两次，结果还是那个数。
- ~ 按位取反：0变1，1变0。
- << 左移：左移 n 位相当于乘以 2 的 n 次方。  
- \>> 右移：右移 n 位相当于除以 2 的 n 次方。
- 应用场景：
  1. 判断整数奇偶：num % 2 == 0 或者 num & 1 (得到最低位)。
  2. 交换两个变量的值（不使用额外空间）：
     ```c
     a = a ^ b;
     b = a ^ b;
     a = a ^ b;
     ```
  3. 输出二进制的每一位（从最高位依次打印）：
     ```c
     int offset = 31;
     while (offset >= 0) {
         int res = (value >> offset) & 1;
         printf("%d", res);
         offset--;
     }
     ```

#### 2. 数组

- 定义：一组相同类型的数据的有序集合。
- 声明：类型 数组名[元素个数];，如 int ages[5];（告诉系统存储多少数据，每条数据是什么类型）。
- 初始化：
  - 完全初始化：int ages[3] = {1, 3, 5};（可省略元素个数）。
  - 部分初始化：int ages[3] = {1, 3};（剩余元素补 0）。
  - 指定初始化：int ages[3] = {[0]=1, [2]=3};
- 存储与获取：数组名称[索引号] = 值; / 数组名称[索引号];
- 遍历：使用 for 循环取出所有元素。
- 数组长度：sizeof(ages) / sizeof(ages[0])（总大小/单个元素大小）。
- 存储细节：从内存地址大的开始分配存储空间。

#### 3. 枚举与宏定义

- 枚举 (enum)：整型变量，4字节。声明 enum name { ... }; 或 typedef enum { ... } name;。默认从 0 开始，逐个 +1。
- 宏定义 (#define)：如 #define LED_ON 1。纯文本替换。
- 区别：枚举有类型、有作用域、方便调试；宏定义没有类型检查。

### 六、 C++ 进阶与指针

#### 1. C++ 基础补充

- 换行：\n 效率高于 endl（endl 会刷新缓冲区）。
- extern：声明变量，不分配内存，可以多次声明。典型用法：跨文件共享变量。
- auto：自动类型推导（必须初始化）。默认会去掉引用 & 和顶层 const。
- using：声明，引入命名空间成员。
- 类型转换：静态转换 static_cast<目标类型>(变量)，如 float f = static_cast<float>(i);。
- 常用数学函数：log, pow, hypot, sqrt, abs (整数绝对值), fabs (浮点数绝对值), floor。
- 常用字符串函数：strcpy, strcat, strlen, strcmp, strchr, strstr。

#### 2. 指针基础

- & 取地址，* 解引用。
- 声明与赋值：
  ```cpp
  int num = 10;
  int *p;      // 声明指针
  p = &num;    // 赋值
  int *p2 = &num; // 或声明时直接赋值
  ```
  p 存的是内存地址，*p 存的是地址里对应的值。
- 空指针：int *p = NULL; 或 C++11 的 int *p = nullptr;。
- 野指针：未赋值的指针，非常危险，不能使用。

#### 3. 指针运算与数组

- 指针类型决定 +1 跨越的字节数（char* +1字节，int* +4字节，double* +8字节）。
- 数组名默认就是首元素的地址。*(p+1) 等价于 v[1]。
  ```cpp
  int v[] = {1, 2, 3};
  int *p = v; // 默认为 v[0] 的地址
  ```

#### 4. 动态内存分配 (new/delete)

- 申请：new type; 或 new type[n];（数组空间）。
- 释放：delete 指针; 或 delete[] 指针;。
- 指针悬挂：delete 后指针没有置空，再次使用会崩溃。
  - 不要轻易进行指针之间的赋值。
  - 一旦 delete，确保这块内存没人再用。

#### 5. 常量和引用

- const int *p; （指向常量的指针：存储值不可变，但指针可修改指向）。
- int * const p = 地址; （常量指针：存储值可变，指针不可修改指向，必须初始化）。
- const int * const p = 地址; （指向常量的常量指针：值和指向均不可改）。
- 引用：int &b = a;（b 是 a 的别名，底层用指针实现，但语法更安全，常用于函数传参和动态内存分配场景）。
