Linux基础命令

pwd           查看当前文件所在文件夹路径
ls            列出当前文件夹里面所有文件
cd+文件夹名   进入指定文件夹
cd ..         退出当前文件夹
touch         新建空白文件
.md           Markdown文件
cat           查看文件里面内容
rm            删除文件
mv            给文件重命名
cp            复制文件


Git

git config          设置身份（名字，邮箱）
git config --list   查看配置好的身份信息
git add .           把所有改动加入暂存区
git commit -m""     正式
git push            将本地的上传至GitHub网页仓库
