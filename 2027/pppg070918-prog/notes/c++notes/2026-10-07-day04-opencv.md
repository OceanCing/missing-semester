## 二、示例代码

源码位置：

```text
cpp/opencv/day04_basics.cpp
```

功能流程：

1. 使用 `cv::imread` 读取 `input.jpg`。
2. 使用 `image.empty()` 判断读取是否成功。
3. 使用 `cv::cvtColor` 把 BGR 图转换为灰度图。
4. 使用 `cv::threshold` 进行固定阈值二值化。
5. 使用 `cv::imwrite` 保存 `gray.jpg` 和 `binary.jpg`。

核心代码：

```cpp
cv::Mat image = cv::imread("input.jpg", cv::IMREAD_COLOR);
if (image.empty()) {
    std::cout << "Failed to read input.jpg" << std::endl;
    return -1;
}

cv::Mat gray;
cv::cvtColor(image, gray, cv::COLOR_BGR2GRAY);

cv::Mat binary;
cv::threshold(gray, binary, 127, 255, cv::THRESH_BINARY);

cv::imwrite("gray.jpg", gray);
cv::imwrite("binary.jpg", binary);
```

## 六、今天必须理解

- `cv::Mat` 是 OpenCV 保存图像像素的矩阵类型。
- `image.empty()` 返回 `true` 时，说明图片没有读取成功。
- OpenCV 默认读取的彩色图片通道顺序是 BGR，不是 RGB。
- 灰度图通常只有一个通道，每个像素表示亮度。
- `cv::threshold(gray, binary, 127, 255, cv::THRESH_BINARY)` 表示：
  - 像素值大于 127 时，输出 255，也就是白色。
  - 像素值小于等于 127 时，输出 0，也就是黑色。
- `imread` 负责读取图片，`imwrite` 负责保存图片。
