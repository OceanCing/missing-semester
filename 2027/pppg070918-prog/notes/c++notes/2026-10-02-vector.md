# `std::vector` 动态数组

## 今日目标

- 理解 `vector` 和普通数组的区别，知道什么时候该用它。
- 掌握 `vector` 的定义、初始化和常用成员函数。
- 掌握四种遍历方式，并知道该用引用还是值。
- 区分 `size` 和 `capacity`，会用 `reserve` 避免反复扩容。
- 知道什么操作会让迭代器、引用、指针失效。

## 1. 为什么需要 `vector`

内置数组 `int a[10];` 有两个硬伤：长度必须是编译期常量，而且不能自动增长。

```cpp
int a[10];        // 固定 10 个元素，多了少了都别扭
a[10] = 1;        // 越界，编译器不报错，运行时才崩
```

`vector` 是标准库提供的动态数组，长度可以运行时决定，也可以随时增删元素，并且能自动管理内存（不需要手写 `new` / `delete`）。

## 2. 头文件与命名空间

```cpp
#include <iostream>
#include <vector>

using namespace std;   // 把标准库的名字全部引入当前作用域

vector<int> numbers;   // 之后可以直接写 vector，不用写 std::vector
```

`using namespace std;` 是黑马课程里的常用写法，写起来短、适合练习和刷题。

需要注意：它是把标准库里所有名字都倒进来，项目代码里容易和别的库撞名（比如 `count`、`size`）。所以有两种写法：

```cpp
// 练习 / 刷题：省事
using namespace std;
vector<int> v;

// 项目里更稳：只引入用到的名字，或者干脆写全 std::
using std::vector;
std::vector<int> v2;
```

本笔记的代码统一用 `using namespace std;`，方便和课程保持一致；看别人的项目代码时见到 `std::vector` 也不要慌，是同一个东西。

## 3. 定义与初始化

```cpp
vector<int> numbers;          // 空 vector
vector<int> scores(5);        // 5 个元素，值初始化成 0
vector<int> zeros(5, -1);     // 5 个元素，都是 -1
```

注意：`vector<int> v[5];` 是「5 个空 vector 的数组」，和 `vector<int> v(5);` 完全不同，圆括号和方括号不要写错。

初始化方式：

```cpp
vector<int> v1;                        // 空
vector<int> v2 = {1, 2, 3};            // 列表初始化，推荐
vector<int> v3{1, 2, 3};               // 同上
vector<int> v4(4, 10);                 // {10, 10, 10, 10}
vector<int> v5(v3);                    // 拷贝构造
vector<int> v6(v3.begin(), v3.end());  // 迭代器区间
```

坑：`vector<int> v{5};` 是「一个元素 5」，`vector<int> v(5);` 是「五个 0」。花括号优先匹配列表初始化。

## 4. 常用成员函数

| 操作 | 说明 | 平均复杂度 |
| --- | --- | --- |
| `v.push_back(x)` | 尾部插入 `x` 的拷贝 | O(1) |
| `v.emplace_back(args...)` | 尾部就地构造，通常比 `push_back` 少一次拷贝 | O(1) |
| `v.pop_back()` | 删除尾部元素（不返回它） | O(1) |
| `v.size()` | 元素个数，返回无符号类型 | O(1) |
| `v.empty()` | 是否为空，优先于 `v.size() == 0` | O(1) |
| `v.front()` / `v.back()` | 首 / 尾元素的引用 | O(1) |
| `v[i]` | 下标访问，不做越界检查 | O(1) |
| `v.at(i)` | 下标访问，越界抛 `out_of_range` | O(1) |
| `v.clear()` | 清空元素，容量一般不变 | O(n) |
| `v.resize(n)` | 改变元素个数，变长时补 0 | O(n) |
| `v.reserve(n)` | 只改容量，不改元素个数 | O(n) |
| `v.insert(pos, x)` | 在 `pos` 前插入，后面元素整体后移 | O(n) |
| `v.erase(pos)` | 删除 `pos` 处元素，后面元素整体前移 | O(n) |

```cpp
vector<int> v;
v.push_back(1);
v.push_back(2);
v.emplace_back(3);

cout << v.size() << '\n';  // 3
cout << v.front() << ' ' << v.back() << '\n';  // 1 3

v.pop_back();                   // {1, 2}
v.clear();                      // 空，但 capacity 通常还是原来那么大
```

## 5. 四种遍历方式

```cpp
vector<int> v = {1, 2, 3, 4, 5};

// 1. 下标：需要下标时用
for (size_t i = 0; i < v.size(); ++i) {
    cout << v[i] << ' ';
}

// 2. 范围 for + 值：只读、元素小（如 int）时用
for (int x : v) {
    cout << x << ' ';
}

// 3. 范围 for + 引用：要修改元素，或元素是大对象时用
for (int& x : v) {
    x *= 2;                     // 直接改到原元素
}

// 4. 范围 for + const 引用：只读 + 元素大，避免拷贝
for (const int& x : v) {
    cout << x << ' ';
}
```

只要循环体里不需要修改元素，就优先写 `const auto&`，既不会拷贝也不会误改。

## 6. `size`、`capacity` 和 `reserve`

- `size()`：当前真正存放了多少个元素。
- `capacity()`：不重新分配内存的前提下最多能放多少个元素。
- 当 `size == capacity` 再插入时，`vector` 会申请一块更大的内存（通常是 2 倍），把元素搬过去，再释放旧内存。

```cpp
vector<int> v;
v.reserve(1000);        // 一次申请够，避免中途反复搬家
for (int i = 0; i < 1000; ++i) {
    v.push_back(i);     // 这里不会再扩容
}
```

已知元素总量时先 `reserve`，是刷题里很常见的提速手段。

## 7. 迭代器、引用、指针失效

扩容时会重新分配内存，所以下面这些情况之后，之前保存的迭代器 / 引用 / 指针都可能失效：

- 发生扩容后的 `push_back`、`emplace_back`、`insert`。
- `insert` / `erase` 之后，插入点或删除点之后的迭代器。
- `reserve` 之后全部失效。

```cpp
vector<int> v = {1, 2, 3};
int& first = v[0];
v.push_back(4);         // 可能扩容
// first 现在可能是悬空引用，不要再使用
```

删除元素的正确写法：

```cpp
for (auto it = v.begin(); it != v.end(); ) {
    if (*it % 2 == 0) {
        it = v.erase(it);   // erase 返回下一个有效位置
    } else {
        ++it;
    }
}
```

## 8. 二维 `vector`

```cpp
// 3 行 4 列，全部为 0
vector<vector<int>> grid(3, vector<int>(4, 0));

grid[1][2] = 9;                 // 正常下标访问

// 行数不固定的情况：先建行，再逐行 push
vector<vector<int>> rows(3);
for (int i = 0; i < 3; ++i) {
    rows[i].push_back(i);
}
```

`vector<vector<int>>` 的每一行是独立分配的内存，行之间不连续；追求缓存性能且列数固定时，可以考虑用一维 `vector` 手动映射下标 `i * cols + j`。

## 9. 易错点

- 用 `v[i]` 访问越界下标，不报错但结果未定义；不确定时用 `v.at(i)`。
- 在 `v.size() == 0` 时调用 `v.front()` / `v.back()`，未定义行为。
- 循环里边遍历边 `push_back` / `erase`，导致迭代器失效或死循环。
- `for (auto x : v)` 里改 `x`，改的是副本，原 vector 没变。
- 把 `v.size()` 和 `int` 比较时，有符号 / 无符号混用会出警告，建议用 `size_t`。
- `clear()` 只清元素，不释放容量；想真正释放可以 `vector<int>().swap(v);`。
- 头文件要写 `#include <vector>`，不要依赖别的头文件间接包含。
- 只写了 `vector<int> v;` 却忘了 `#include <vector>` 或 `using namespace std;`。

## 10. 完整示例代码

下面是把全文示例串起来的完整程序，可直接在 C++17 环境编译运行。

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    // 1. 初始化
    vector<int> numbers = {5, 3, 8, 1};

    // 2. 尾部增删
    numbers.push_back(9);
    numbers.emplace_back(2);
    numbers.pop_back(); // 去掉 2

    // 3. 大小与容量
    cout << "size = " << numbers.size()
         << ", capacity = " << numbers.capacity() << '\n';

    // 4. 引用遍历：把每个元素加 1
    for (int& x : numbers) {
        ++x;
    }

    // 5. const 引用遍历：只读且不拷贝
    cout << "numbers:";
    for (const auto& x : numbers) {
        cout << ' ' << x;
    }
    cout << '\n';

    // 6. 删除所有偶数：erase 返回下一个有效位置
    for (auto it = numbers.begin(); it != numbers.end();) {
        if (*it % 2 == 0) {
            it = numbers.erase(it);
        } else {
            ++it;
        }
    }
    cout << "odds:";
    for (const auto& x : numbers) {
        cout << ' ' << x;
    }
    cout << '\n';

    // 7. reserve 与 size/capacity 的关系
    vector<int> buffer;
    buffer.reserve(10);
    cout << "after reserve: size = " << buffer.size()
         << ", capacity = " << buffer.capacity() << '\n';

    // 8. 二维 vector：3 行 4 列
    vector<vector<int>> grid(3, vector<int>(4, 0));
    grid[1][2] = 9;
    cout << "grid[1][2] = " << grid[1][2] << '\n';

    // 9. 字符串 vector
    vector<string> names = {"Da", "Xiao"};
    names.emplace_back("Zhan");
    cout << "names:";
    for (const auto& name : names) {
        cout << ' ' << name;
    }
    cout << '\n';

    return 0;
}
```
