- **基础设置**：`cmake_minimum_required(VERSION 3.10)` 指定版本；`project(MyProj CXX)` 定义项目名和语言。
    
- **添加可执行文件/库**：`add_executable(app main.cpp)` 生成可执行文件；`add_library(mylib STATIC src.cpp)` 生成静态库（`SHARED` 为动态库）。
    
- **指定头文件目录**：`target_include_directories(app PRIVATE include/)`，`PRIVATE` 仅当前目标用，`PUBLIC` 会传递给依赖者。
    
- **链接库**：`target_link_libraries(app PRIVATE mylib)` 链接库；`find_package(OpenCV REQUIRED)` 查找系统包，之后用 `${OpenCV_LIBS}` 链接。
    
- **变量与条件**：`set(SRC a.cpp b.cpp)` 设置变量，用 `${SRC}` 引用；`if(WIN32)` 判断系统，支持 `else()` 和 `endif()`。
    
- **循环与函数**：`foreach(file ${SRC})` 遍历列表；`function(func_name arg)` 封装逻辑，用 `cmake_parse_arguments` 解析命名参数。
    
- **生成与拷贝**：`add_custom_command(TARGET app POST_BUILD COMMAND ${CMAKE_COMMAND} -E copy_if_different $<TARGET_FILE:app> ./bin/)`，常用于拷贝动态库或资源。
    

> **关键记忆点**：现代 CMake 极力推荐使用 `target_*` 命令（如 `target_compile_definitions`、`target_compile_features`）来精确控制每个目标的编译选项，避免使用全局的 `add_definitions` 或 `include_directories`。


## 例子
```
cmake_minimum_required(VERSION 3.28)  
project(cpp_learn)  
  
set(CMAKE_CXX_STANDARD 26)  
  
add_executable(cpp_learn main.cpp)
```

### project()
**设置内置变量**：CMake 会自动生成一系列以项目名命名的变量，方便后续引用。
```
project(cpp_learn)   #cpp_learn为函数名
#将生成
 用内置变量指定头文件目录
# ${cpp_learn_SOURCE_DIR} 会自动替换为 /home/xxx/cpp_learn
target_include_directories(app PRIVATE ${cpp_learn_SOURCE_DIR}/include)
# 用内置变量指定源文件路径
add_executable(app ${cpp_learn_SOURCE_DIR}/src/main.cpp)
```

## 拆分路径

| `get_filename_component(<var> <path> NAME)`      | 获取文件名（含扩展名）    |
| ------------------------------------------------ | -------------- |
| `get_filename_component(<var> <path> NAME_WE)`   | 获取文件名（不含扩展名）   |
| `get_filename_component(<var> <path> EXT)`       | 获取文件扩展名        |
| `get_filename_component(<var> <path> DIRECTORY)` | 获取所在目录路径       |
| `get_filename_component(<var> <path> ABSOLUTE)`  | 获取绝对路径         |
| `get_filename_component(<var> <path> REALPATH)`  | 获取真实路径（解析符号链接） |
### 用法

foreach(HEADER ${HEADERS})
