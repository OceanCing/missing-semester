**动态库（Dynamic Library）** 是一种在**程序运行时**才被加载和链接的代码库

| 类型  | 链接时机 | 文件（Windows） | 文件（Linux） |
| --- | ---- | ----------- | --------- |
| 静态库 | 编译时  | `.lib`      | `.a`      |
| 动态库 | 运行时  | `.dll`      | `.so`     |

**静态库**：编译时把库代码**复制**进你的 exe，exe 变大，但独立运行。  
**动态库**：编译时只记录"我要用这个库"，运行时才去加载 `.dll`/`.so`。

## 动态库的优点

1. **节省内存和磁盘**  
    多个程序可**共享**同一份库，不用每个 exe 都复制一遍。
2. **更新方便**  
    只替换 `.dll`/`.so`，不用重新编译主程序（前提是接口没变）。
3. **模块化** 
    插件系统、热更新都靠动态库实现。
4. **按需加载**  
    可以运行时才加载（如 `LoadLibrary` / `dlopen`），不用就不占内存。

## cmake
```

add_library(mylib SHARED
    src/mylib.cpp
)
# 头文件目录
target_include_directories(mylib PUBLIC
    ${CMAKE_CURRENT_SOURCE_DIR}/include
)
```
