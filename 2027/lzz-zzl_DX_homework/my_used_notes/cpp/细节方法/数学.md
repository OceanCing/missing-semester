
C++ 常用数学函数（都在 `<cmath>`）：

## 基本

|函数|作用|
|---|---|
|`abs(x)` / `fabs(x)`|绝对值|
|`pow(x, y)`|x 的 y 次方|
|`sqrt(x)`|平方根|
|`cbrt(x)`|立方根|
|`fmod(x, y)`|浮点取余|

## 指数对数

| 函数                | 作用       |
| ----------------- | -------- |
| `exp(x)`          | e^x      |
| `log(x)`          | ln(x)    |
| `log2(x)`         | log₂(x)  |
| `log10(x)`        | log₁₀(x) |
| pow(int 底，int 次数) |          |
|                   |          |

## 取整

|函数|作用|
|---|---|
|`ceil(x)`|向上取整|
|`floor(x)`|向下取整|
|`round(x)`|四舍五入|
|`trunc(x)`|截断小数|

## 三角

|函数|作用|
|---|---|
|`sin(x)` `cos(x)` `tan(x)`|正弦/余弦/正切（弧度）|
|`asin(x)` `acos(x)` `atan(x)`|反三角|
|`atan2(y, x)`|由坐标求角|

## 比较

|函数|作用|
|---|---|
|`fmax(x, y)`|较大值|
|`fmin(x, y)`|较小值|
|`isnan(x)` `isinf(x)`|判断 NaN / 无穷|

## 常用

cpp

const double PI = acos(-1.0);   // π
const double EPS = 1e-9;        // 浮点比较精度

## 示例

cpp

```cpp
#include <cmath>
cout << sqrt(16);      // 4
cout << pow(2, 10);    // 1024
cout << ceil(2.1);     // 3
cout << floor(2.9);    // 2
cout << log10(1000);   // 3
```

**注意**：三角函数用弧度（角度 × π / 180）；浮点比较用 `fabs(a-b) < EPS`，别用 `==`。
