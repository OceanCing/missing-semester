## ++
```
//it++ 与 ++it;
auto it = 某容器.begin;   //假设为1
auto it1 = it++; // it1 为1 ，然后it+1

  
// 前置递增
auto it1 = ++it;   // it 先变成指向 2，然后 it1 也指向 2

//在for中效果一样，++it效率更高

```
对于迭代器（尤其是**双向迭代器**如 `list`、`map` 的迭代器）：

- **`++it`（前置）**：直接让迭代器指向下一个元素，**不需要复制**
    
- **`it++`（后置）**：需要**先复制一份旧值**，再自增，最后返回旧值副本
