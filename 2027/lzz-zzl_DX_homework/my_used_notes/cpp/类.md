## 列表初始化

```
class Aclass(){
public:
	Aclass(int a,int& r) : a(a),r(r)
private:
	const int a;
	int& r 
}
```
### 为什么初始化列表更好？

| 对比项         | 初始化列表          | 函数体赋值                |
| ----------- | -------------- | -------------------- |
| **执行时机**    | 对象**构造时**直接初始化 | 对象构造后**再赋值**         |
| **效率**      | 更高（一步到位）       | 稍低（先构造默认值，再赋值）       |
| **const成员** | 可以初始化          | 不能赋值（const变量只能初始化一次） |
| **引用成员**    | 可以初始化          | 不能赋值（引用必须初始化）        |

## const成员函数
```
class MyClass {
private:
    int value;
public:
    // const成员函数：在函数声明后面加 const
    int getValue() const {  
        return value;       //  可以读取
        // value = 10;      //  错误！不能修改
    }
    
    // 非const成员函数
    void setValue(int v) {  
        value = v;          //  可以修改
    }
};
```
