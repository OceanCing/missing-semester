## 文件目录操作
```shell
ls     #查看
cd ~/dir 

cd ..   #退回上级
cp file file_cp_name
mv na1 na2       #重命名 或移动
rm   # 删
cat    # 查看
less   # 分页查看

touch   #创建空文件或更新文件时间戳
```
#### 组合
```
name= "aa"    #创建量
echo "$name"  #显示量
|    #管道
&&    #条件
```

## 概念
### 文件时间
Linux 文件有三种时间：

| 时间        | 含义              |
| --------- | --------------- |
| **atime** | 最后访问时间 (access) |
| **mtime** | 最后修改时间 (modify) |
| **ctime** | 状态改变时间 (change) |
```shell
touch existing.txt           # 把 atime 和 mtime 都更新为当前时间
```
