## ros_control



懒得打了

`ros_control` 提供了多种开箱即用的控制器，主要分为以下几类：

- **关节状态控制器 (`joint_state_controller`)**：只负责将硬件接口中的关节状态（位置、速度等）发布为 `sensor_msgs/JointState` 话题，供其他节点使用。
    
- **位置控制器 (`position_controllers`)**：控制关节到达指定的位置。`joint_position_controller` 会使用 PID 将位置误差转换为力或速度输出。
pid去参数服务器读取

- **速度控制器 (`velocity_controllers`)**：控制关节以指定的速度运动
    
- **力/力矩控制器 (`effort_controllers`)**：直接对关节施加指定的力或力矩
    
- **轨迹控制器 (`joint_trajectory_controllers`)**：用于平滑地执行整个运动轨迹，常用于机械臂控制

## 仿真时
### 使用gazebo_ros_control
在 Gazebo 里，数据流是这样循环的：

1. **控制器计算**：你的 `joint_position_controller`（位置控制器）收到 MoveIt! 发来的目标位置，结合当前状态，通过 PID 计算出需要的**力矩**（`effort`）
    
2. **写入 Gazebo**：这个力矩值不会发给真实电机，而是通过硬件接口，由 `gazebo_ros_control` 插件直接施加到 Gazebo 模型对应的 **虚拟关节**上
    
3. **物理仿真**：Gazebo 的物理引擎（如 ODE）根据施加的力矩、连杆质量、惯性矩阵等，计算出关节的**新位置和速度**。
    
4. **状态反馈**：Gazebo 再将新的关节状态（位置、速度）通过 `joint_state_controller` 发布出来，供控制器进行下一轮计算，形成闭环

## 写控制器类
### 先继承
```
class Controller  
    : public controller_interface::Controller<  
          hardware_interface::VelocityJointInterface>{
          
    }
```

### 必须实现的四个虚函数

| 函数                     | 何时被调用        | 干什么            |
| ---------------------- | ------------ | -------------- |
| `init(hw, nh)`         | 控制器**加载时**一次 | 读参数、拿关节句柄、订阅话题 |
| `starting(time)`       | 控制器**启动时**一次 | 初始化状态，通常清零     |
| `update(time, period)` | **每个控制周期**调用 | 核心计算，发指令       |
| `stopping(time)`       | 控制器**停止时**一次 | 停止动作，通常归零      |
## 必须持有的成员变量

### 1. 关节句柄

```cpp
std::vector<hardware_interface::JointHandle> joints_;
```

**作用**：每个轮子一个句柄，`update()` 里通过 `joints_[i].setCommand(v)` 给轮子发速度。

**哪来的**：`init()` 里用 `hw->getHandle("joint_name")` 拿到。

---

### 2. 订阅者
```cpp
ros::Subscriber cmd_sub_;
```
**作用**：订阅 `/cmd_vel`，接收外部速度指令。

**为什么要有**：控制器得知道“车该往哪走”，这个信息来自 `cmd_vel`。

---

### 3. 最新指令缓存

cpp
```cpp
geometry_msgs::Twist cmd_;
```
**作用**：回调收到指令后存在这里，`update()` 从这读。

**为什么要有**：回调在非实时线程，`update()` 在实时线程，用一个成员变量传递最新值，是最简单安全的做法。

---

### 4. 运动学参数

```cpp

double wheel_radius_;      // 轮子半径
double R_;                 // 轮子到中心距离
std::vector<double> alpha_; // 每个轮子的安装角
int n_;                    // 轮子数
```
**作用**：逆运动学公式需要这几个数。

**哪来的**：`init()` 里从 YAML 读。

---

### 5. 回调函数

```cpp
void cmdVelCallback(const geometry_msgs::Twist& msg);
```
**作用**：收到 `cmd_vel` 时把消息存进 `cmd_`。

**不放在 public**：外部不需要调用它，是内部机制。

## 注册插件
#### 在package.xml中添加编译插件的依赖
```xml
<build_depend>controller_interface</build_depend>  
<build_depend>hardware_interface</build_depend>  
<build_depend>pluginlib</build_depend>  
<build_depend>geometry_msgs</build_depend>  
<build_depend>roscpp</build_depend>  
  
<exec_depend>controller_interface</exec_depend>  
<exec_depend>hardware_interface</exec_depend>  
<exec_depend>pluginlib</exec_depend>  
<exec_depend>geometry_msgs</exec_depend>
```
#### package.xml导出插件
```xml
<export>
  <controller_interface plugin="${prefix}/standard_plugin.xml"/>
</export>
```
含义：
- 这个包提供了一个 **`controller_interface` 类型的插件**。
- 插件的描述文件是包根目录下的 `standard_plugin.xml`
