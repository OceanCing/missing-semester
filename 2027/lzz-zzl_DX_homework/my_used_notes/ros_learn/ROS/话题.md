节点之间沟通

### 创建
```
ros::Publisher pub = n_handle.advertise<std_msgs::String>("my_public", 100);

//其中 n_handle为句柄
```
### 发布
```
std_msgs::String msg;  //创建 对应的量
char str[10];  
snprintf(str, 10,"%d", counter);  
msg.data = str;     //赋值
pub.publish(msg);  //发送
```

### 接收
#### 回调函数
```
//回调函数，参数是接受的类型
void chatterCallback(std_msgs::String msg) {  
    printf(msg.data.c_str());  
    printf("\n");  
}  
```
#### 建句柄，添加订阅
```
ros::NodeHandle n;  
  
ros::Subscriber sub = n.subscribe("my_public", 10, chatterCallback);
```
#### 接受
```
while(ros::ok()) {  
    ros::spinOnce();  
}
```



## 命令行查看话题
```
rostopic list   //查看活跃话题

rostopic echo /话题名称      //查看话题内容

rostopic hz   /话题名称     //发送频率

rostopic info /scan        //话题发布和接受的节点,结构
```
