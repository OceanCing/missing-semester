# 参数服务器 
|特点|说明|
|---|---|
|**全局共享**|所有节点都能访问|
|**键值对存储**|通过"名字"来存取"值"|
|**类型灵活**|支持 int、float、string、bool、数组、字典|
|**持久化**|参数在节点启动后一直存在，直到 master 关闭|
|**动态修改**|运行中可以读取、修改参数|

## 参数加载

xml

```xml
<!-- 直接加载 YAML 文件 -->
<rosparam command="load" file="$(find smb_control)/config/control.yaml" />
<!-- 或者直接写在 launch 中 -->
```
<param name="max_velocity" value="1.1" />

---

### 方法：通过命令行加载


## 使用
##### 终端:
列出：
```
rosparam list
```
获取值：
```
rosparam get 参数名
```
设置：
```
rosparam set 参数名 value
```
#### C++
```
#include <ros/ros.h>

double max_vel;
ros::param::get("/smb_velocity_controller/max_velocity", max_vel);

// 或使用 NodeHandle
ros::NodeHandle nh;
nh.getParam("/max_velocity", max_vel);
```
