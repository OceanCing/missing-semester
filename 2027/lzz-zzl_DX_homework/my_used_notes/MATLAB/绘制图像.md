## 常用美化技巧

| 命令                       | 作用        |
| ------------------------ | --------- |
| xlabel('x');ylabel('y'); | 轴名称       |
| title('正弦与余弦函数');        | 标题        |
| legend('x')              | 图例        |
| `grid on`                | 显示网格      |
| `axis equal`             | 等比例坐标轴    |
| `xlim([a b])`            | 设置x轴范围    |
| `ylim([a b])`            | 设置y轴范围    |
| `legend(...)`            | 添加图例      |
| `subplot(m,n,p)`         | 子图布局      |
| `hold on` / `hold off`   | 保持/取消当前图像 |
| `figure`                 | 新建图形窗口    |

## 多线
```
plot(x, y1, 'r-', x, y2, 'b--', 'LineWidth', 1.5);legend('sin(x)', 'cos(x)');  % 图例
grid on;
xlabel('x');
ylabel('y');
title('正弦与余弦函数');
```

- `'r-'`：红色实线；`'b--'`：蓝色虚线
- 常用颜色：`r`红、`g`绿、`b`蓝、`k`黑、`m`品红、`c`青
- 常用线型：`-`实线、`--`虚线、`:`点线、`-.`点划线



## 三维图像
```
[X, Y] = meshgrid(-5:0.1:5, -5:0.1:5);
Z = sin(sqrt(X.^2 + Y.^2));
surf(X, Y, Z);      % 曲面图
% mesh(X,Y,Z);      % 网格图（可选）
colorbar;
xlabel('x'); ylabel('y'); zlabel('z');
title('z = sin(\surd(x^2+y^2))');
```

## `subplot(m, n, p)` 
是 MATLAB 里用来**在同一个图形窗口里排列多个子图**的命令
- `m`：把窗口分成 **m 行**
- `n`：把窗口分成 **n 列**
- `p`：当前要在**第 p 个格子**里画图
