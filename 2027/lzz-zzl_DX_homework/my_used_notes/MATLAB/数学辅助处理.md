```
syms a n c ;   %创建变量
```
```
eq = s== a^2/2;   %创建方程
```

eq_r = rhs(eq);  %返回等号右边
lhs()       %同理
subs(eq1,m,n)；  %把eq1中的用n替换m
eq2_num = subs(eq2_sub, [a, b], [2, 3]);可以同时替换多个变量

## 处理
```
solve(f,x)   %解方程,变量为x
%如：
[x1,x2] =solve（a*x^2 + b*x + c == 0, x） % 返回求根公式（带a、b、c）

solve([f1,f2],[x,y]) %解方程组 自变量应该是sym(符号变量)类型
%solve要求方程的个数等于未知数的个数

vpasolve(eq, x)     %强制数值解避免解不出来

```


## `syms` 应该包含：

1. **时间自变量**：`t`
    
2. **广义坐标**：`x(t)`, `th(t)`（它们是 `t` 的函数）
    
3. **物理常数**：`m`, `M`, `g`, `l1`, `l2`, `I`
    
4. **外力/输入**：`F`
    
5. **约束力**：`Fx`, `Fy`（虽然是未知量，但它们是代数变量，不是时间的函数）
