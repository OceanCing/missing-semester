# 传递函数->状态空间方程
## 用ss函数
```
% 1. 首先定义传递函数模型
num = [1];      % 分子系数
den = [1, 3, 2]; % 分母系数，代表 s^2 + 3s + 2
sys_tf = tf(num, den);

% 2. 使用 ss() 函数转换为状态空间模型
sys_ss = ss(sys_tf);

% 3. 提取 A, B, C, D 矩阵
[A, B, C, D] = ssdata(sys_ss);
```
