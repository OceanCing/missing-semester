## tf
表示LTI传递函数的对象

| 属性               | 含义                                         |
| ---------------- | ------------------------------------------ |
| **Numerator**    | 分子多项式系数，用元胞数组表示（支持 MIMO 多输入多输出，每个元素是一个多项式） |
| **Denominator**  | 分母多项式系数，同样用元胞数组表示                          |
| **Variable**     | 传递函数使用的变量名，这里是 `'s'`，表示连续系统                |
| **IODelay**      | 输入输出总延迟（I/O delay），这里为 0                   |
| **InputDelay**   | 输入延迟，这里为 0                                 |
| **OutputDelay**  | 输出延迟，这里为 0                                 |
| **InputName**    | 输入信号名称，空表示未命名                              |
| **InputUnit**    | 输入信号单位，空表示未指定                              |
| **InputGroup**   | 输入通道分组信息（用于 MIMO 系统）                       |
| **OutputName**   | 输出信号名称                                     |
| **OutputUnit**   | 输出信号单位                                     |
| **OutputGroup**  | 输出通道分组信息                                   |
| **Notes**        | 用户备注，这里是空的字符串数组                            |
| **UserData**     | 用户自定义数据，空                                  |
| **Name**         | 系统名称，空                                     |
| **Ts**           | 采样时间。`0` 表示连续时间系统；`-1` 表示未指定；正数表示离散采样周期    |
| **TimeUnit**     | 时间单位，这里是 `'seconds'`                       |
| **SamplingGrid** | 用于表示系统数组（LTI array）中每个模型的采样点信息             |
