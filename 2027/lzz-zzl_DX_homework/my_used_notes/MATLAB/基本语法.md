## 循环
```
a = [10 20 30 40 50];
for k = 1:length(a)
    disp(a(k));      % 逐个访问
end
```


## 函数
```
f = @(x) x.^2 + 2*x + 1;   % 定义
y = f(3);                  % 调用，结果 16

g = @(x,y) x.^2 + y.^2;    % 两个参数
g(1,2);                    % 结果 5
```

脚本末尾定义
```
function y = myFunc(x)   % 函数定义必须放在脚本末尾
    y = sin(x) + x.^2;
end
```
