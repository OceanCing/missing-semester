## 事件
#### 发布事件
```
esp_event_post( 
	MY_VALUE_EVENT,
	VALUE_BECAME_FOUR,
	&value,
	sizeof(value),
	portMAX_DELAY 
);
```
#### 回调函数
###### 编写回调函数
```
static void value_event_handler(void *arg, esp_event_base_t base, int32_t id, void *data){
	//函数内容
}
//参数的格式是必须一样的
```
###### 注册事件和对应的回调函数
```
esp_event_handler_instance_register( 
	MY_VALUE_EVENT,   //事件的大类 要注册
	VALUE_BECAME_FOUR,    //具体事件   可以分别注册，也可以一类一块注册
	&value_event_handler, //回调函数
	NULL,             //额外参数，就是回调函数的*arg
	NULL             //返回值,类型：esp_event_handler_instance_t *，可用于注销事件
)
```

## 三个过程的关系

| 概念        | 1. 发布事件 (`esp_event_post`) | 2. 注册监听 (`esp_event_handler_instance_register`) | 3. 回调函数 (`event_handler`)     | 说明                                                |
| --------- | -------------------------- | ----------------------------------------------- | ----------------------------- | ------------------------------------------------- |
| **事件大类**  | `event_base`               | `event_base`                                    | `esp_event_base_t event_base` | 标识事件所属的模块（如 `WIFI_EVENT` 或自定义的 `MY_VALUE_EVENT`）。 |
| **事件ID**  | `event_id`                 | `event_id`                                      | `int32_t event_id`            | 标识具体的事件类型（如 `VALUE_BECAME_FOUR`）。                 |
| **附加数据**  | `event_data`               | -                                               | `void *event_data`            | 事件携带的具体数据（如 `&value`）。**注意：注册时不需要传数据。**           |
| **用户上下文** | -                          | `handler_arg`                                   | `void *arg`                   | 注册时传入的自定义参                                        |

## 等待事件完成
xEventGroupWaitBits

##### 使用案例
```
xEventGroupWaitBits(
	s_wifi_event_group,                   //事件组
    WIFI_CONNECTED_BIT | WIFI_FAIL_BIT,   /* 等待这两个事件 */    
    pdFALSE,                               /* 收到后不清除标志位 */    
    pdFALSE,                               /* 结束条件 */   
    portMAX_DELAY);                        /* 无限等待，直到事件发生 */
```
