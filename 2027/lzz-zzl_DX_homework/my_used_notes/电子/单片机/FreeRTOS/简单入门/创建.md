1. 单片机上电
   ↓
2. 执行 main() 函数
   ↓
3. 初始化硬件（GPIO、TIM、SPI、ADC...）
   ↓
4. 初始化 OLED、FOC、串口等外设
   ↓
5. 调用 osKernelInitialize()  ← 初始化 FreeRTOS 内核
   ↓
6. 调用 MX_FREERTOS_Init()    ← 创建所有任务（但不运行）
   ↓
7. 调用 osKernelStart()        ← 启动调度器，任务开始运行
   ↓
8. main() 函数的 while(1) 循环 ← 此时 main 变成了一个普通任务


```
const osThreadAttr_t OLED_task_attributes = {  
    .name = "OLED_task",  
    .stack_size = 512  * 4,  
    .priority = (osPriority_t) osPriorityAboveNormal,  
};  
osThreadId_t OLED_taskHandle = osThreadNew(OLED_Task, NULL, &OLED_task_attributes);
```
在主函数放这段就创建好了
