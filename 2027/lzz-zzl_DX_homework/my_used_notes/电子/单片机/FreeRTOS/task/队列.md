### 使用流程
声明
```
QueueHandle_t joy_queue;
```
在任务创建前创建
```
joy_queue = xQueueCreate(5, sizeof(joy_event_t));
```
发布
```
xQueueSend(joy_queue, &evt, 0);    0为不阻塞
```
接收
```
if (xQueueReceive(joy_queue, &evt, portMAX_DELAY) == pdTRUE) {
//放数据处理
}
```


## 二进制信号量

### 创建
```
static SemaphoreHandle_t s_connect_sem = NULL;
void init(){
	//在函数中初始化
	s_connect_sem = xSemaphoreCreateBinary();
}
```
### 发布
```
xSemaphoreGive(s_connect_sem);
```

### 接收
```
if (xSemaphoreTake(s_connect_sem, ticks) == pdTRUE) {
        // ✅ 接收到信号量（连接成功）
        return true;
    }
```
无限阻塞 ->portMAX_DELAY
