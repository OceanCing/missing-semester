# 业务逻辑

**核心业务**

实现多模态交互 + 具身物理陪伴，支持极速日常交互与深层情感疗愈，保障用户的心理安全、家庭隐私，并确保全年龄段交互内容的绝对合规与健康。

**参与角色**

主用户（使用者）、监护人（针对儿童或老人）、专业心理咨询师（高危介入介入）、智能小A（具身智能体）

**核心业务流程**

1. **日常极速反馈：** 用户语音/触摸触发 → 本地预缓存与动态路由拦截 → 门槛内问题直接本地调用缓存的极速回复 + 简单物理反馈（如点头、闭眼享受）。
2. **深度情感沟通：** 用户发起复杂开放话题 → 路由上云请求大模型 → 门锁空当期本地触发“动作补偿”（如侧耳倾听） → 云端下发回复 → 拟真TTS发声与动作流同步执行。
3. **心理安全风控：** 本地识别极端情绪/自残倾向 → 触发设备级预警 → 推送告警至监护人APP + 授权开启加密云端通道转接专业咨询师。
4. **合规与话题过滤：** 用户发起涉黄/涉暴/涉政等违规或不适宜话题 → 命中云端/本地动态限制清单（Blocklist） → 阻断原生大模型回复，触发柔性话题转移逻辑（配合摇头微动作） → 引导回安全健康的对话场域。
5. **资产生态更新：** 云端下发新表情/动作配置/最新限制清单 → 后台静默OTA增量更新 → 用户获得全新的交互反馈与IP体验。

**业务规则**

- 敏感数据（互动记忆、心理状态画像）本地存储，严控数据出门。
- 大模型思考空当期，必须强制触发100%的物理部件动作补偿机制。
- 心理干预遵循严格边界，仅进行认知行为疗法（CBT）轻度辅助，严禁下发医疗处方类建议。
- 云端人工介入通道必须在获取用户或监护人明确授权后方可开启。
- 严格执行动态话题限制清单（Blocklist），对违规或不适宜信息进行100%拦截，拦截过程必须以“柔性话术+微动作”转移，严禁生硬报错（如“我无法回答”）破坏沉浸感。

# 需求 功能拆解

**一、用户需求**

1. 告别机械卡顿，像和真人朋友一样实现流畅、自然的对话。
2. 设备不仅能“说”，还要能“动”，有灵动的眼神和真实的肢体反馈。
3. 拥有长期记忆，记住我的喜好、家人和过去的聊天内容，拒绝同质化。
4. 情绪低落时能提供安慰和疏导，但绝不侵犯家庭环境隐私。
5. 产品长期使用不枯燥，性格和动作能持续进化或更换。
6. 交互内容绝对健康安全，特别是作为儿童陪伴时，能主动避开或纠正不良话题及有害信息。

**二、拆分功能（分硬件功能+软件功能）**

**硬件端（具身实体）**

- **采集模块：** 远场语音麦克风阵列、触摸感应区域（头部/背部）、环境声/光学传感器。
- **执行模块：** 柔顺控制单轴/多轴电机（控制头部/耳朵微动）、动态表情屏幕（眼部UI）、高保真扬声器。
- **通信与计算模块：** Wi-Fi/蓝牙通信模组、端侧SBC计算芯片、本地大容量安全存储芯片。

**软件端（手机APP + 云端服务 + 端侧模型）**

1. **手机APP功能：** 设备配网绑定、权限与角色管理（监护人模式）、本地记忆库查看与编辑（LTM可视化）、异常情绪告警接收、数字资产商城（IP音色/动作包）。
2. **云端功能：** 复杂开放话题大模型推理、表情与动作策略OTA资源池分发、加密人工心理干预通道、数字资产鉴权、动态话题限制清单（Blocklist）的实时维护与下发。
3. **端侧固件功能（核心）：** 预缓存管理、意图路由分发、LTM图谱向量检索、本地CBT心理状态初步诊断、拟真TTS语音合成、传入云端隐私信息模糊化处理、限制清单比对拦截与柔性话题转移逻辑。

# 整体架构

**整体分层架构（云-边-端软硬件融合架构）**

1. **感知&执行层（底层硬件层）**

   智能小A整机：麦克风、触摸传感器、柔顺控制电机、表情屏幕、通信与供电模组。

2. **边缘计算与固件层（内置软件/端侧AI）**

   跑在设备SBC芯片里的程序：动态模型路由、动作补偿触发逻辑、本地向量记忆库（LTM DB）、心理状态特征提取与CBT诊断、敏感词与合规内容校验模块、硬件驱动。

3. **云端服务层（后台大模型软件）**

   千亿参数语言大模型（处理复杂对话）、资产OTA分发服务器、安全鉴权与加密通信服务、心理专家接警与连麦系统、动态合规限制清单数据库。

4. **应用端层（前端软件）**

   手机APP（iOS/Android），面向主用户/监护人的配置、记忆管理与预警接收界面。

**简易拓扑流转**

- **高频日常交互：** 用户发话/触摸 → 端侧路由校验为高频场景 → 端侧调取缓存与记忆 → 硬件直接执行语音与动作（毫秒级极速响应）。
- **复杂深度对话：** 用户发话 → 端侧路由判定上云 → *同时*硬件电机执行“思考”动作补偿 → 云端大模型推理返回结果 → 端侧TTS与动作引擎解析 → 硬件发声并配合表情执行。
- **心理高危干预：** 用户表现极端情绪 → 端侧心理特征提取命中高危阈值 → 端侧上报加密告警 → 云端推送至监护人APP → 授权通过 → 建立云端与设备的直接连麦通道进行干预。
- **不良话题过滤：** 用户发话涉及不适宜内容 → 端侧/云端命中限制清单（Blocklist） → 阻断大模型原生回复逻辑，端侧调用“柔性转移话术” → 硬件配合摇头等微动作，将话题自然引导至安全场域。
- **OTA生态更新：** APP端购买/订阅新动作包（或系统静默更新合规清单） → 云端下发动作配置文件(`.yaml`)/清单库 → 端侧静默接收并覆盖本地文件 → 用户下一次交互即触发新规则。
