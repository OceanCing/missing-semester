# 第一课笔记

## 一、Linux基础

### 1.1常见操作系统与Linux发行版

常见系统有：windows、macOS与Linux
Linux与发行版
- Linux通常指内核
- 发行版提供一套可以安装和使用的系统

### 1.2机器人开发中的Linux

- 机器人带着小电脑，运行Ubuntu Server
- 开发电脑通过shh远程编辑、编译或运行机器人主机上的程序。
- 程序在机器人主机上运行，完成对机器人的操控与调试

### 1.3 Linux 目录与路径

- `/`根目录：总入口
- `/etc`：存放系统配置文件
- `/usr`：存放程序和库
- `/var`：存放日志等可变数据
- `/dev`：存放设备文件 

## 二、shell基础

### 2.1 终端、Shell 与命令

- 终端：提供输入命令的界面
- Shell：解释命令并安排执行，如Bash、Zsh
- 程序：执行具体操作，如 `ls` 查看目录内容

### 2.2 Shell 命令的结构

- 结构：命令 [选项] [参数]
- 命令：做什么，如 `ls` 列出目录内容
- 选项：怎么执行，如 `-l` 显示详细信息、`-a` 显示隐藏项
- 参数：指定操作对象，如 `~/projects`

### 2.3 当前位置与切换目录

- `pwd`：显示当前目录
- `ls`：列出目录的内容
- `cd 目录`：进入指定目录
- `cd ..`：返回上一级目录
- `cd ~`：返回家目录

### 2.4 文件和目录操作

- `mkdir -p`：创建目录，补齐缺少的父目录
- `touch`：创建空文件或更新时间
- `cp`：复制文件
- `mv`：移动或重命名
- `rm`：删除文件，通常不进回收站
- `cat`：直接显示文件内容
- `less`：分页查看文件内容，按 `q` 退出

### 2.5 Shell 的常用组合

- 变量：保存一个值，如 `name="RM"`，用 `"$name"` 引用变量
- 重定向：把输出写入文件，`>` 覆盖写入，`>>` 追加写入
- 管道 `|`：把前一个命令的输出交给后一个命令
- 条件连接 `&&`：前一条命令成功后，才执行后一条

### 2.6 快捷操作

- `ls --help`：查看ls的选项和用法
- `man ls`：查看ls的手册，按 `q` 退出
- `Tab`：补全命令或路径
- `↑`、`↓`：调出历史命令

## 三、Vim 编辑器

### 3.1 Vim 与模式

- Vim：在终端中编辑文件，常用于SSH远程开发
- 普通模式：移动、删除、复制
- 插入模式：输入文本
- 命令行模式：保存、退出

### 3.2 必备按键

- 普通模式按 `i`：进入插入模式，开始输入文字
- 插入模式按 `Esc`：返回普通模式
- 普通模式按 `:`：进入命令行模式，输入保存、退出等命令
- `h j k l`：左、下、上、右移动
- `dd`：删除当前行，`yy`：复制当前行，`p`：粘贴
- `u`：撤销，`/word`：搜索word
- `:w`：保存文件，`:q`：退出，有未保存修改时通常会阻止退出
- `:wq`：保存并退出，`:q!`：放弃未保存修改并退

## 四、Git 与 GitHub

### 4.1 Git与GitHub的分工

- Git：本地版本控制
- GitHub：托管远程仓库

### 4.2 Git的四个位置

- 工作区：存放正在编辑的文件
  git add——
- 暂存区：存放准备提交的内容
  git commit——
- 本地仓库：保存已经提交的版本记录
  git push——
- 远程仓库：保存上传到GitHub的提交记录
- `commit` 只提交到本地，`push` 才上传到远程

### 4.3 提交作者与SSH认证

- 作者信息：说明修改由谁提交
- SSH认证：验证远程访问权限
- 公钥.pub：添加到GitHub用于认证
- 私钥：保留在本机，不上传、不分享

### 4.4 获取仓库与查看修改

- `git clone 仓库地址`：下载仓库和提交历史
- `git status`：查看当前分支和文件状态
- `git diff`：查看尚未暂存的修改
- `git log --oneline`：简短查看提交历史

### 4.5 分支与提交

- 分支：保留独立开发线，修改完成后评审合并
- `git switch -c 分支名`：创建并切换分支
- `git switch 分支名`：切换已有分支
- `git add 文件`：暂存指定文件的修改
- `git commit -m "说明这次改了什么"`：创建本地提交
- `git push -u origin 分支名`：推送分支并设置跟踪关系
- `git pull`：获取并整合当前分支的远程更新

### 4.6 Fork与PR工作流

- 工作流：Fork到个人仓库、Clone、创建分支、修改/add/commit、push、发起PR
