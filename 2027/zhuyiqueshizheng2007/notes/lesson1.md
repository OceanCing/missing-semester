## 1. Linux基础
- `/`可衍生不同的路径:
  - `/home/user` 用户文件
  - `/etc`       系统配置
  - `/usr`       程序与库
  - `/var`       日志等可变数据
  - `/dev`       设备文件
> 其中，`/home/user/example` 为**绝对路径**，从/开始;
> `./hello.txt` 为**相对路径**，从当前位置开始;
> `~/example` 为**home目录**中的example。

## 2. vim && Shell（课堂与预习笔记结合）

### vim简单指令：
- h为上，h为左，j为下，l为右
- 返回正常模式：`esc`
- 退出当前编辑器且不保存：`:q!`

- 基本操作：
  - 删除光标所在字符：`x`
  - 插入：`i`
  - 添加：`a`
  - 保存文件：`wq`

- 删除类：
  - 从光标处删除至词尾：`de`
  - 从光标处删除至下一词头：`dw`
  - 从光标处删除至行尾：`d$`
> 由此可引申出一个基本格式：code+[num]+motion,即行为+【数字】+执行对象

- 撤销类：
  - 撤销最后执行的一次命令：`u`
  - 恢复至本行初始状态：`U`
  - 撤回撤销指令：`CTRL+r`

- 置入类：
  - 将最后一次删除内容置入光标后：`p`
> 若换行输入，则在置入位置上方末尾`p`

- 替换类：
  - `r`+*任意字母*，光标字母替换为该字母

- 更改类：
  - `ce`+*字符串*，从文本改至单词末尾（同时进入**插入模式**）
  - `c`同基本格式相同

> 1.0版本，后期会完善

### Shell基本指令：
- `ls`看文件；`cd`进目录；`pwd`看当前位置
- `cp`复制；`mv`移动（改名）；`rm`删除
- `cat`看文件内容；`grep`搜索文本；`bat`看或改文件
- `echo`输出；`chmod`改权限

- 变量和引号：
```bash
    name="Alice"
    echo"Hello,$name"
```

> 注意：等号两边不能有**空格**
> 特别的，`$1`为第一个参数；`$#`为参数个数；`$?`为上条命令是否成功

- 条件判断：
```bash
    if[-Z "$1"];then
        echo"请输入一个参数"
        exit 1
    fi
```

> 常记：-Z "$var" 变量为空；-f **文件** 文件；-d **目录** 目录

- 函数：
```bash
    greet(){
        local name="$1"
        echo"Hello,$name"
    }
    greet"Tom"
```

> 注意：函数变量前加local，避免影响外部

## git && github
- Git 与 GitHub 重点笔记

  - 1. Git 与 GitHub 的区别
 **Git**：本地版本控制系统。用于记录每次提交、比较修改、查看历史、创建分支。
 **GitHub**：远程托管与协作平台。用于托管 Git 仓库、发起 PR（Pull Request）、讨论和评审代码。

  - 2. Git 的三大区域与提交流程
  修改代码后，代码需要经过三个区域的流转才能到达远程仓库：
   **工作区** (正在编辑的文件)
   **暂存区** (本次提交的内容清单)
   **本地仓库** (已记录的提交历史)

> **核心命令流转**：
> `git add` -> `git commit` -> `git push`

- `git add`：将工作区的修改添加到暂存区。
- `git commit`：将暂存区的内容提交到本地仓库（**只记录到本地**）。
- `git push`：将本地仓库的提交发送到远程仓库（如 GitHub）。

  - 3. 初次使用配置
    配置提交作者信息
    每次提交都需要记录是谁提交的：
```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

- 分支管理
```bash
git switch -c feature/hello   # 创建并切换到新分支
git switch main               # 切回主分支
git pull                      # 获取并整合当前分支的远程更新
```
