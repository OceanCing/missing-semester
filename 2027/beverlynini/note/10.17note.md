# Linux
## 目录
### 1.绝对路径
从 / 开始，就算是第一级，主目录也是。E.g. /home/user/example
### 2.相对路径
从当前位置开始。 E.g. HOME文件夹里面有文件 home.txt，现在在文件夹里面，那么可以通过 ./home.txt 来打开文件脚本，其中“.”用于简写HOME
### 3. 家目录 ~
E.g.cd ~:回到家目录    ～/example：家目录中的example目录
### 4.常见目录
| 目录名 | 含义 | 解释 |
| :--- | :--- | :--- |
|/home/user| 用户文件 | 个人电脑桌面 |
|/etc| 系统配置 | 网络配置，安全驱动配置等 |
|/usr| 程序与库 | 安装的程序放置的地方 |
|/var| 日志等可变数据 | 运行状态，报错等 |
|/dev| 设备文件 | / |
# 终端，Shell，命令程序
终端--输入输出命令-->Shell(Bash/Zsh(Bash pro))--向机器解释命令，组织执行-->程序系统
## 1.Shell命令的结构
命令【做什么】+ 选项【怎么执行】+ 参数【操作哪个对象】
E.g. cat -n hhh.txt //cat:打印文件内容 -n:给输出的每一行标行号 hhh.txt:操作的对象
## 2.补充
(1) 短/长选项
| 短选项 | 长选项 |
| :---: | :---: |
|ls -l|ls -long|
|rm -f|rm -force|
(2) 查看说明书
man(manual,手册)命令，如：man ls //查看ls的所有选项
## 3.一些常用命令，以及部分命令的详细用法
| 命令 | 作用 | 详细用法 |
| :---: | :--- | :--- |
|pwd|显示当前目录| / |
|ls|列出当前所在目录内容|ls -a可以把隐藏的文件也显示出来；ls -l列出按顺序排列的文件，并显示一系列详细信息|
|cd|切换目录|cd 目录名（进入该目录）；cd ..（返回上一级)|
|mkdir|创建目录/文件夹|mkdir 文件夹/目录名字（在当前目录下创建单个文件夹）；mkdir -p A/B/C/D （补全父目录，创建A/B/C/D四个有顺序的文件夹）|
|touch|创建空文件，或更新时间| / |
|cp|复制文件|cp 要复制的对象 复制到的目标|
|mv|移动或重命名|mv 旧名字 新名字（将旧名字重命名为新名字）|
|rm|删除文件，直接删除不进入回收站| / |

## 4.一些常用组合
- 变量 E.g. name = "RM" //定义变量name，赋值为RM
- 重定向 E.g. echo "hello" > hello.txt //文件hello.txt中的内容用hello覆盖（文件内容完全变为hello）；将>换成>>，则是把hello追加到hello.txt的文件内容末尾
- 管道 E.g. ls -a | grep txt // | :把左边的信息传到右边；grep:搜索命令，寻找包含特定符号的行。 ---> 把通过ls -a查看的一大堆文件信息中带txt字样的行挑选出来显示在屏幕上
- 条件连接 E.g. mkdir -p demo && cd demo //先创建文件夹demo，再执行cd demo的命令
## 5.技巧补充
1. 命令 --help：快速查看该命令的选项和用法
2. man 命令：打开手册中关于该命令的部分（类查字典），按q(quit)退出
3. tab:补全命令/文件名
4. 👆/👇：调出历史命令
5. history:查看近期敲过的一千行命令，用【!+序号】来重复执行某一行

# Git&Github
Git：本地版本控制；Github：远程托管与协作
简单来说，类似于本地与云端的关系
## git
- 工作区--git add--> 暂存区 --git commit--> 本地仓库 --git push--> 上传至github远程仓库
- 初次使用git提交，需要提交作者信息
  git config --global user.name" " //提交作者名字
  git config --global user.email"  " //提交邮箱
- 查询状态
  git config --get user.name //查询作者名字
  git config --global --list //可以显示作者名字邮箱
- SSH认证：证明本地有访问远程仓库的权限
步骤：
1. ssh-keygen -t ed25519 -C "  " //生成新的SSH密钥。ed25519是一种算法，双引号内填一个“名字”，比如系统/电脑名称，这样可以在github上面看到SSH公钥所属系统/电脑
2. SSH密钥默认存放在 ~/.ssh/id_ed25519 中
3. ls -al ~/.ssh  //查看SSH密钥
4. cat ~/.ssh/id_ed25519.pub 可以打印出SSH公钥，把这个公钥添加在Github中就可以了
5. ssh -T git@github.com 测试连接，确认SSH密钥的添加状态

- git常用命令
| git clone 仓库地址 | 下在仓库以及提交历史 |
| --- | --- |
|git status|查看当前分支和文件状态|
|git diff|查看尚未保存的修改|
|git log --oneline|用间断格式查看提交历史|
|git switch -c hello|创建并切换到分支hello|
|git add hello.txt|暂存文件|
|git commit -m" "|本地提交文件，双引号内填概要|
|git push -u origin feature/hello|推送并建立跟踪关系|
|git swich main|切回主分支|
|git pull|获取并整合当前分支的远程更新|

## PR工作流
团队仓库--fork--> 个人仓库 --git clone--> 复制到本地电脑 ----> 编辑/git add/git commit --git push--> 个人fork接收来自本地的提交
----> 发起个人PR（pull&request) ----> 评审 ----> Merge合并到团队仓库
