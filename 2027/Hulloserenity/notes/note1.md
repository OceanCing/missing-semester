# DynamicX 培训第一课

## 1. Linux

### 1.1 不同系统的差异

| Windows 11 | macOS | Ubuntu（Linux） |
| --- | --- | --- |
| 常见于个人桌面 | Apple 生态 | **服务器、机器人、嵌入式** |

### 1.2 Linux 与发行版

- Linux 通常指内核。
- 发行版提供一套可以安装和使用的系统。

### 1.3 Linux 的目录

| `/home/user` | `/etc` | `/usr` | `/var` | `/dev` |
| --- | --- | --- | --- | --- |
| 用户文件 | 系统配置 | 程序与库 | 日志与可变数据 | 设备文件 |

路径的表示方式：

| `/home/user/example` | `./hello.txt` | `~/example` |
| --- | --- | --- |
| 绝对路径：从 `/` 开始 | 相对路径：从当前位置开始 | home 目录中的 example |

> 注意：路径大小写敏感；`~` 是当前用户的家目录，`.` 是当前目录，`..` 是上一级目录。

## 2. Shell

### 2.1 终端、Shell 与命令

终端输入命令，由 Shell 解释，再交给程序执行。

### 2.2 Shell 命令的结构

Shell 命令的基本结构为：

```text
命令【选项】【参数】
```

| 结构 | 示例 | 意义 |
| --- | --- | --- |
| **命令** | `ls` | **做什么** |
| **选项** | `-la` | **怎样执行**，其中 `-l` 表示显示详细信息，`-a` 表示包含隐藏项 |
| **参数** | `~/projects` | **操作哪个对象**，这里是目标目录 |

### 2.3 当前位置与目录切换

| 命令 | 作用 |
| --- | --- |
| `pwd` | 显示当前目录 |
| `ls` | 列出目录内容 |
| `cd 目录` | 进入指定目录 |
| `cd ..` | 返回上一级 |
| `cd ~` | 返回家目录 |

### 2.4 文件和目录操作

| 命令 | 作用 | 示例 |
| --- | --- | --- |
| `mkdir -p` | 创建目录，允许补齐父目录 | `mkdir -p linux_demo` |
| `touch` | 创建空文件或更新时间戳 | `touch hello.txt` |
| `cp` | 复制文件 | `cp hello.txt hello-copy.txt` |
| `mv` | 移动或重命名 | `mv hello-copy.txt backup.txt` |
| `rm` | 删除文件 | `rm backup.txt` |
| `cat` / `less` | 直接查看 / 分页查看 | `cat hello.txt` |

### 2.5 Shell 的四种常用组合

#### 变量

```bash
name="RM"; echo "$name"
```

#### 重定向

```bash
echo "hello" > hello.txt
```

`>` 表示覆盖写入，`>>` 表示追加到文件末尾。

#### 管道

```bash
ls -la | grep txt
```

将前一个程序的输出交给下一个程序处理，这里用于筛选包含 `txt` 的内容。

#### 条件连接

```bash
mkdir -p demo && cd demo
```

前一条命令成功后，再执行下一条命令。

### 2.6 陌生命令的帮助入口

| 命令 | 作用 |
| --- | --- |
| `ls --help` | 快速查看选项和用法 |
| `man ls` | 打开手册，按 `q` 退出 |

## 3. Vim

### 3.1 Vim 模式

Vim 有三种常用模式，分别为普通模式、插入模式和命令行模式。

- 普通模式用于浏览、查找文本。
- 插入模式用于修改文本。
- 命令行模式用于保存或退出。

普通模式按 `i` 进入插入模式；按 `:` 进入命令行模式。

按 `Esc` 返回普通模式。

### 3.2 必备按键

普通模式：

| 按键 | 操作 |
| --- | --- |
| `h` `j` `k` `l` | 左 / 下 / 上 / 右 |
| `dd` | 删除当前行 |
| `yy` / `p` | 复制 / 粘贴当前行 |
| `u` | 撤销 |
| `/word` | 搜索 `word` |

命令行模式：

| 命令 | 操作 |
| --- | --- |
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` | 保存并退出 |
| `:q!` | 放弃修改并退出 |

## 4. Git 与 GitHub

### 4.1 Git 与 GitHub 的分工

- **Git：本地版本控制**
  - 记录每次提交。
  - 比较修改、查看历史。
  - 为新功能创建分支。
- **GitHub：远程托管与协作**
  - 托管 Git 仓库。
  - 通过 PR 讨论和评审。
  - 合并团队认可的修改。

### 4.2 Git

#### Git 的四个位置

1. **工作区**：正在编辑的文件。通过 `git add` 转移到暂存区。
2. **暂存区**：本次提交的内容清单。通过 `git commit` 提交到本地仓库。
3. **本地仓库**：已记录的提交历史。通过 `git push` 推送到 GitHub 远程仓库。
4. **GitHub 远程仓库**：远程保存的提交历史。

#### 常用命令

| 命令 | 作用 |
| --- | --- |
| `git clone <仓库地址>` | 下载仓库及提交历史 |
| `git status` | 查看当前分支和文件状态 |
| `git diff` | 查看尚未暂存的修改 |
| `git log --oneline` | 用简短格式查看提交历史 |
| `git switch -c feature/hello` | 创建并切换到功能分支 |
| `git add hello.txt` | 暂存指定文件 |
| `git commit -m "Add greeting"` | 记录一次本地提交 |
| `git push -u origin feature/hello` | 推送并建立跟踪关系 |
| `git switch main` | 切回主分支 |
| `git pull` | 获取并整合当前分支的远程更新 |

### 4.3 GitHub

工作流程：

```text
团队仓库 -> 个人 Fork（仓库副本） -> clone 到本地电脑 -> feature 分支
         -> add -> commit -> push -> 个人 Fork 接收 -> PR -> Review -> Merge
```
