## 快捷键和基本命令
### 1. 在普通界面

和 Windows 一样：

* 复制：Ctrl + C
* 粘贴：Ctrl + V
* 剪切：Ctrl + X

### 2. 在终端

因为 Ctrl + C 在终端里代表“强制中断当前运行的程序”，所以终端里不能用它来复制。

* 复制：Ctrl + Shift + C
* 粘贴：Ctrl + Shift + V

### 3. 万能鼠标中键

* 选中即复制：用鼠标左键划选任何文字（哪怕是终端里的文字），它就已经自动复制到剪贴板了。
* 中键粘贴：把鼠标光标放到你要粘贴的地方，按下鼠标滚轮（中键），就直接粘贴出来了。

```bash
cd 或 cd ~ 或 cd $HOME        # 回到当前用户的主目录（如 /home/用户名）
cd /                # 切换到根目录
cd ..               # 返回上一级目录
cd ../..            # 返回上两级目录
cd -                # 回到上一次所在的目录
cd /path/to/dir     # 切换到绝对路径目录
cd dirname          # 切换到当前目录下的子目录（相对路径）
cd ~/Documents      # 切换到主目录下的 Documents
cd "目录名含空格"     # 目录名含空格时需加引号或转义
```

```bash
pwd                 # 显示当前所在目录
cat                 # 直接在终端把文件打印出来
less                # 分页查看长文件内容（按空格翻页，按q退出）
ls                  # 列出当前目录内容
ls -l               # 详细列表
ls -a               # 显示隐藏文件
ls -la              # 详细列表+隐藏文件
mkdir 目录名         # 创建目录
mkdir -p a/b/c      # 递归创建多级目录
rmdir 目录名         # 删除空目录
rm -r 目录名         # 递归删除目录及内容
cp -r 源 目标        # 递归复制目录
mv 源 目标           # 移动/重命名
tree                # 树状显示目录结构（需安装）
```

```bash
touch 文件名.后缀                # 文件不存在则创建空文件；存在则更新时间戳
touch file1 file2              # 一次创建/更新多个文件
touch -a 文件名                 # 只更新访问时间
touch -m 文件名                 # 只更新修改时间
touch -t 202601011200 文件名    # 把时间设为指定时间
```

```bash
find . -name "*.txt"            # 在当前目录及子目录找所有 txt 文件
grep "hello" a.txt              # 在 a.txt 里找 "hello" 这个词

> 文件名.后缀          | —————   # 重定向创建空文件（会清空已有内容，慎用）
echo "" > 文件名.后缀  |         # ""代表空字符
```

```bash
#!/bin/bash

# 1. 最基本的功能：输出一段文字（自动换行）
echo "1. Hello, Ubuntu! 这是最基本的输出。"

# 2. 输出变量（$ 符号用来提取变量的值）
name="小明"
echo "2. 你好，$name！这是输出变量的值。"

# 3. 输出命令的执行结果（用 $(命令) 语法）
echo "3. 当前时间是：$(date)"
echo "3. 你当前所在的目录是：$(pwd)"

# 4. -n 选项：输出后不换行（光标会停在末尾）
echo -n "4. 这句话后面不会换行..."
echo "接着打印这句。"

# 5. -e 选项：开启转义字符（让 \n, \t 等生效）
echo -e "5. 开启转义：\n   - 这里的 \\n 变成了换行\n   - 这里的 \\t 变成了制表符（Tab）"

# 6. 输出特殊字符：单引号和双引号的区别
echo "6. 双引号会解析变量: $name"
echo '6. 单引号会原样输出: $name'

# 7. 创建文件（你刚才问的用法）
echo "7. 这句话被写进文件了！" > demo.txt
echo "   （你可以用 cat demo.txt 查看刚刚写进去的内容）"

# 8. 追加内容（用 >> 不会覆盖原文件）
echo "8. 这是追加的第二行。" >> demo.txt
echo "   （现在 demo.txt 里有两行话了）"
```

```bash
chmod +x 文件名.后缀        # 赋予文件可执行权限
./文件名.后缀               # 运行该文件（./是表示在当前目录下查找该文件，即相对路径，/就是绝对路径，可能误操作，很危险）
```
