# Missing Semester Class 1 Notes
Topic: Linux, Vim & Shell, Git & GitHub

## 1. Shell
Shell is an interface to interact with operating system.
We can run commands, combine them with pipes, redirect input and output.
Common operators:
- `>` : redirect output to file
- `|` : pipe, pass output of one command to another
- `>>` : append content to file

## 2. Vim
Vim is a modal text editor.
Two basic modes:
- Normal mode: for navigation and command
- Insert mode: for typing text
Shortcuts:
- `i` : enter insert mode
- `Esc` : back to normal mode
- `:wq` : save and quit

## 3. Git & GitHub
Git is a distributed version control system.
Common workflow:
1. Fork the target repository
2. Clone my forked repo with SSH
3. Create new branch for development
4. Modify files, use `git add` and `git commit`
5. Push branch to remote, open a PR to upstream repo

SSH key is used for authentication without password.
