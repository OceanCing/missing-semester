# Linux Shell Vim Git 第一课

## Linux 基础:

### 常用命令:

- `cd` 切目录，`..` 是上一层，`.` 是当前目录
- 在终端里 `export` 一个变量，关了窗口就没了
- 要长期用的环境变量得写到 `~/.bashrc` 里，不然下次开终端又没了

### 重定向和管道:

- `>` 是覆盖写入，`>>` 是追加
- `|` 管道，前一个命令的输出直接当后一个的输入
- 命令后面加 `--help`帮者
- `man 命令名`，man是manual手册

## Vim

三种模式，刚进去是普通模式，不能直接打字

- 普通模式：按各种快捷键操作
- 插入模式：能正常打字编辑
- 命令模式：输命令（保存退出之类的）

多行删除：普通模式下先输个数字，比如 10，再按删除，就从光标往下删10行。想全删就输个超大的数字再删

## Git & GitHub

- 工作区：你改代码的地方
- 暂存区：`git add` 放进去的东西
- 本地仓库：`git commit` 提交进去的记录

改代码  `add` 到暂存  `commit` 到本地  `push` 到远程

`commit message` 用英文写，别写中文

### SSH 密钥

推代码不想每次输密码就配 SSH key成一对密钥，公钥传到 GitHub 上，私钥自己留好别给人

### 分支开发 + PR

- `fork` 上游仓库到自己账号下
- 新建个分支在上面改
- 改完 `push` 到自己的远程仓库
- 给上游发 `PR` 让人审核
- 审核过了就合并进去
