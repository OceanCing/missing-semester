# XML、Xacro与URDF
## 总体认识
- XML:是一种用于组织、存储和传输数据的标记语言。在 ROS 中，它主要用于描述机器人模型，也用于进程间通信
- URDF:用树状结构描述机器人的刚体、关节及其连接关系，是机器人模型的基础描述格式
- Xacro:在 URDF 的基础上提供参数、表达式和宏，便于复用相同结构，减少重复定义
## XML
- XML由有层级关系的元素组成，一个文档只能有一个根元素。元素可以包含其他元素、文本和属性，属性值必须使用引号
### 书写
- 只有一个根元素
- 标签正确嵌套并保持大小写一致
- 每个元素都有对应的结束标签，或使用自闭合标签
- 属性值必须加引号
## URDF
- URDF通过`link``joint`、`transmission`和扩展标签共同描述机器人：
### Link
#### link描述一个刚体
- `inertial`：质量、转动惯量和质心偏移等物理属性。
- `visual`：几何形状、材质和视觉位姿。
- `collision`：碰撞几何形状和碰撞位姿，可与视觉形状一致，也可扩大以形成安全区域。
### Joint
`joint` 指定父连杆和子连杆，并通过 `origin` 描述从父连杆坐标系到子连杆坐标系的变换。它还可以定义运动轴和运动限制。

#### 主要关节类型
- fixed
- revolute
- continuous
- prismatic
- floating
- planar
### Transmission
- transmission描述电机等执行器与关节之间的机械关系，是接入ros_control的重要部分。它支持位置、速度和力矩等控制接口，并可设置机械减速比。
## Xacro
### Xacro 核心能力
- 是参数化和封装
- 属性用于统一定义尺寸、质量等参数，并可在表达式中复用
- 宏用于封装重复出现的link、joint和transmission等结构
- 宏可以接收多个参数并设置默认值
- 对于左右对称部件，可通过前缀、编号或反射参数复用同一宏
## Gazebo 与 ros_control
### 插件主要承担工作
1. 读取 URDF 中的transmission，确定受控关节和控制接口。
2. 将 Gazebo 中的关节状态转换为ros_control可识别的虚拟硬件接口。
3. 初始化controller_manager，支持动态加载和切换控制器。
4. 同步仿真时钟、关节状态与控制指令，形成从状态读取、控制计算到指令写回的闭环。
