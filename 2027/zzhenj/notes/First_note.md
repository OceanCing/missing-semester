# Linux、Vim && Shell、Git && GitHub 学习笔记 

## 一.Linux 
### 1.Linux目录和路径
　　`～`是家目录

　　`.`是当前目录 

　　`..`是上一级目录
| | |
| --- | --- |
| `/home/user` | 用户文件 |
| `/etc` | 系统配置 |
| `/usr` | 程序与库 |
| `/var` | 日志等可变数据 |
| `/dev` | 设备文件 |

　　绝对路径：从/开始

　　相对路径：从当前位置开始

　　**路径的大小写敏感**

## 二.Shell
### 1.shell命令结构
　　命令 [选项][参数]
　　命令：要做什么

　　选项：怎么去做(eg：-a是显示隐藏内容) 

　　参数：操作的对象

### 2.常用命令
| | |
| --- | --- |
| `pwd` | 显示当前目录 |
| `ls` | 列出目录内容 |
| `cd` | 进入指定目录 |
| `mkdir -p` | 创建新目录，允许补全父目录 |
| `touch` | 创建文件 |
| `cp` | 复制文件 |
| `mv` | 移动或重命名 |
| `rm` | 删除文件 |
| `cat` | 直接查看/分页查看 |

　　**rm通常不进回收站，删除前需谨慎**

### 3.常用组合
| | |
| --- | --- |
| 变量 | 保存一个值，再通过$+变量名引用它 |
| 重定向 | 命令 > 文件名，>是覆盖写入，>是追加到文件末尾 |
| 管道 | 命令1 \| 命令2，将1的输出交给2 |
|条件连接 | 命令1 && 命令2，1成功后再执行2 |

### 4.陌生命令的帮助入口
　　遇到陌生命令不知道怎么用的时候，可以在命令后加 `--help`**快速查看选项和用法** eg：`ls --help`

　　或者在命令前加man**打开手册**，按q退出，eg：`man ls`

　　Tab可以补全命令或路径，↑/↓可以调出历史命令

## 三.Vim
### 1.Vim模式
　　vi+文件名进入文件后为**普通模式**

　　按i进入**插入模式**，可以编辑内容，按Esc键退回普通模式

　　普通模式按：进入**命令行输入**

　　命令行输入w为保存，q为退出，wq保存退出，q!放弃修改退出

### 2.普通模式按键
| | |
| --- | --- |
| h/j/k/l | 左/下/上/右 |
| dd | 删除当前行 |
| yy/p | 复制/粘贴当前行 |
| u | 撤销 |
| /word | 搜索某个词 |

## 四.Git和Github
### 1.概念
　　**Git**：本地版本控制，记录每次提交，比较修改，为新功能创建分支

　　**Github**:远程托管Git仓库，通过PR讨论和评审提交，合并认可的修改

### 2.Git的四个位置
　　**工作区**：正在编辑的文件

　　**暂存区**：工作区`git add`之后的内容清单

　　**本地仓库**：暂存区`git commit`之后的提交历史

　　**Github远程仓库**：本地仓库`git push`之后保存的提交历史

### 3.Git常用命令
| | |
| --- | --- |
| `git clone` <仓库地址> | 下载仓库及提交历史 |
| `git status` | 查看文件状态 
| `git diff` | 在git add之前查看修改内容，git add之后无法查看 |
| `git log --oneline` | 简短格式查看提交历史 |
| `git switch -c` 分支名 | 创建并切换到新分支|
| `git commit -m` "修改情况" | 记录本地提交 |
| `git push -u origin` 分支名 | 推送到远程仓库并建立自己的分支 |
| `git pull` | 获取并整合当前分支的远程更新 |

### 4.Github的PR工作流

　　团队仓库 --> 个人Fork--> 在本地电脑进行clone--> 创建分支--> 修改/add/commit--> Push--> 个人Fork接受提交 --> 发起PR --> Review评审 --> Merge到团队仓库

　　*分支：main保持稳定，分支相当于副本，在里面进行修改评审后再合并*
