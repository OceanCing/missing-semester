#27DX培训的第一节课内容笔记
##1. Linux
- **Linux通常指的是内核。**而我们日常安装使用的是『Linux发行版』，是在内核之上搭配桌面环境、命令行工具、软件库、应用软件构成完整操作系统，跟Windows、macOS类似，都能运行程序、管理文件和联网，但常见生态与使用方式不同。Ubuntu(Linux)常见于服务器，机器人、嵌入式，也可以作为桌面系统。
- 团队使用Ubuntu是基于其ROS的兼容性、部署一致性和现有开发生态。
- 机器人开发中的Linux:开发电脑通过链接机器人主机，控制程序可以在无桌面环境运行，这都离不开Linux。
- Linux目录从"/"(也就是根目录)开始,"~"代表家目录。
##2. Vim && Shell
###Vim
**Vim是一个文本编辑器，拥有三种基础模式，分别为普通模式，插入模式，命令行模式。**
打开vim时默认进入普通模式，按'i'/'a'进入插入模式，"esc"回到普通模式，':'进入命令行模式。
常见的几条命令如下：
- 'h'、'j'、'k'、'l'分别时普通模式下的前、下、上、后，'O'、'o'分别是普通模式下的上一行和下一行。
- "yy"复制，'p'贴贴。(普通模式)
- "shift+v"以行为模块选择，"ctrl+v"以单个字符为模块选择。(普通模式)
- 'u'撤回上一次命令。(普通模式)
- "wq"保存并退出，"!q"强制退出不保存。(命令行模式)

###Shell
**Shell是用户和Linux内核之间的"命令解释器"，常见的shell有bash,zsh,sh,fish等。**
关于bash的常见语法：
- "ls":列出目录内容。
- "cd":切换目录。
- "pwd":查看当前所在目录。
- "mkdir":创建文件夹。
- "rm":删除文件。
- "cp":复制。
- "mv":移动/重命名。
- "echo":输出文本。
- "grep":文本搜索。

##3. Git && GitHub
###Git
**Git是分布式版本控制系统,**核心概念如下：
- 工作区：写代码、修改文件的地方。
- 暂存区：临时存放要提交的改动。
- 本地仓库：将暂存区内容保存到本地仓库，可以跟GitHub上的远程仓库相关联。
- 分支：默认主分支叫main,其他分支可自行取名。开发新功能时新建分支，在分支上开发，开发完成后合并到主分支，不会破坏主分支稳定代码。

Git常用基础命令：
- git init                  # 初始化本地git仓库
- git clone 仓库地址        # 克隆远程仓库到本地
- git add 文件名 / git add .# 将改动加入暂存区
- git commit -m "提交说明"  # 提交暂存区内容到本地仓库
- git status                # 查看当前文件状态
- git log                   # 查看提交历史
- git branch                # 查看分支
- git checkout 分支名 / git switch 分支名 # 切换分支
- git merge 分支名          # 合并分支到当前分支
- git pull                  # 拉取远程仓库最新代码并合并
- git push                  # 将本地提交推送到远程仓库

###GitHub
**GitHub 是一个基于 Git 的远程代码托管平台。**主要功能如下：
- 托管Git仓库。
- 通过PR讨论和评审。
- 合并团队认可的修改。
