# 第一堂课笔记
## 1.Linux基础
- Linux 的目录从根目录 / 开始，文件名和路径区分大小写。

| 路径或符号 | 含义 |
| --- | --- |
| `/ `| 根目录 |
| `~ `| 当前用户的家目录，例如 /home/houshen |
| `.` | 当前目录 |
| `.. `| 上一级目录 |
|`/home` | 普通用户的家目录通常位于这里 |
| `/etc` | 系统配置 |
| `/usr` | 程序、库等资源 |
| `/var` | 日志等可变数据 |
| `/dev` | 设备文件 |
- /home/user/example **绝对路径，从/开始**
- ./hello.txt **相对路径，从当前位置开始**
- ~/example **home目录中的example**

## 2.Shell&Vim
### 2.1 常用文件操作
| 命令 | 作用 |
| --- | --- |
| `pwd` | 显示当前目录 |
| `ls -la` | 显示目录详细内容，包含隐藏项 |
| `cd example` | 进入当前目录下的 example |
| `cd ..` | 返回上一级目录 |
| `cd ~` | 回到家目录 |
| `mkdir -p demo/notes` | 创建目录，必要时补齐父目录 |
| `touch hello.txt` | 文件不存在时创建空文件，存在时更新时间戳 |
| `cp hello.txt backup.txt` | 复制文件 |
| `mv backup.txt old.txt` | 移动或重命名文件 |
| `rm old.txt` | 删除文件 |
| `cat hello.txt` | 输出文件内容 |
| `less hello.txt` | 分页查看文件，按 q 退出 |
- **rm通常不进回收站，删除前先确认路径和文件名**

### 2.2 shell的常用四种组合

| 操作 | 示例 | 作用 |
| --- | --- | --- |
| 变量 | `name="RM"; echo "$name"` | 保存一个值，再通过变量引用它 |
| 重定向 | `echo "hello" > hello.txt` | >覆盖写入; >>追加到文件末尾 |
| 管道 | `ls -la \| grep txt` | 将输出交给下一个程序 |
| 条件连接 | `mkdir -p demo && cd demo` | 前一条成功后，再执行下一条|

### 2.3 Vim的常用操作
- **Vim的三种模式：普通模式，插入模式，命令行模式**

| 按键或命令 | 作用 |
| --- | --- |
| `h、j、k、l` | 左、下、上、右 |
| `dd` | 删除当前行 |
| `yy` | 复制当前行 |
| `p` | 在光标后粘贴，整行内容通常粘贴到下一行 |
| `u` | 撤销 |
| `/word` | 向后搜索 word，输入后按回车 |
| `:w` | 保存 |
| `:q` | 退出，有未保存修改时通常会提示 |
| `:wq` | 保存并退出 |
| `:q!` | 放弃未保存修改并退出 |

## 3.Git&Github

### 3.1 Git四个位置
| 位置 | 保存的内容 | 相关操作 |
| --- | --- | --- |
| 工作区 | 正在编辑的文件 | 编辑文件 |
| 暂存区 | 本次准备提交的内容 | `git add` |
| 本地仓库 | 本地提交历史 | `git commit` |
| 远程仓库 | 远程保存的提交历史 | `git push` |
### 3.2 Git常用命令
| 命令 | 作用 |
| --- | --- |
| `git clone <仓库地址>` | 克隆仓库及提交历史 |
| `git status` | 查看当前分支和文件状态 |
| `git diff` | 查看已跟踪文件中尚未暂存的修改 |
| `git log --oneline` | 简要查看提交历史 |
| `git switch -c lesson1` | 从当前版本创建并切换到 lesson1 分支 |
| `git add notes/notes.md` | 暂存指定文件 |
| `git commit -m "Add lesson one notes."` | 将暂存内容提交到本地仓库 |
| `git push -u origin lesson1` | 推送分支并建立上游跟踪关系 |
| `git switch main` | 切换到 main 分支 |
| `git pull` | 获取并整合远程更新 |
### 3.3 推送到github上的流程
Fork 目标仓库 → 克隆到本地 → 创建开发分支 → 修改并保存文件 → 检查修改 → 暂存 → 提交到本地仓库 → 推送到 GitHub → 发起 PR → 根据评审修改并再次推送 → 等待合并。
