# Linux、Shell、Vim、Git 与 GitHub 学习笔记

## 一、Linux 基础

Linux 是操作系统内核，Ubuntu 是常见的 Linux 发行版。Ubuntu 广泛应用于机器人开发、服务器和嵌入式系统。

Linux 文件系统以 `/` 为根目录。

常见路径：

- `/home`：用户目录
- `/etc`：系统配置
- `/usr`：程序和库
- `/var`：日志等可变数据
- `~`：当前用户的家目录
- `.`：当前目录
- `..`：上一级目录

Linux 文件名区分大小写。

## 二、Shell 基础

Terminal 是终端界面，Shell 是负责解释和执行命令的程序。

常用命令：

- `pwd`：显示当前目录
- `ls -la`：查看文件及详细信息
- `cd`：切换目录
- `mkdir -p`：创建目录
- `touch`：创建文件
- `cp`：复制文件
- `mv`：移动或重命名文件
- `rm`：删除文件
- `cat`：查看文件内容

Shell 常见操作：

- `>`：覆盖重定向
- `>>`：追加重定向
- `|`：管道
- `&&`：前一条命令成功后执行后一条
- `$变量名`：引用变量

## 三、Vim 编辑器

Vim 是 Linux 中常见的文本编辑器。

Vim 有三种常用模式：

1. 普通模式：移动光标、复制和删除
2. 插入模式：编辑文本
3. 命令行模式：保存和退出

常用命令：

- `i`：进入插入模式
- `Esc`：返回普通模式
- `:w`：保存
- `:q`：退出
- `:wq`：保存并退出
- `:q!`：不保存直接退出
- `dd`：删除当前行
- `yy`：复制当前行
- `p`：粘贴
- `u`：撤销

## 四、Git 与 GitHub

Git 是分布式版本控制工具，GitHub 是远程代码托管与团队协作平台。

Git 的四个位置：

1. 工作区
2. 暂存区
3. 本地仓库
4. 远程仓库

常用命令：

- `git clone`：克隆仓库
- `git status`：查看状态
- `git diff`：查看修改
- `git switch -c`：创建并切换分支
- `git add`：添加到暂存区
- `git commit`：提交到本地仓库
- `git push`：推送到远程仓库
- `git pull`：获取并整合远程更新

GitHub 团队协作流程：

Fork → Clone → Branch → 修改文件 → Add → Commit → Push → Pull Request → Review → Merge。

## 五、学习心得

通过第一课，我了解了 Linux 开发环境的基本结构，也初步掌握了终端操作、文本编辑和 Git 版本控制的基本流程。
