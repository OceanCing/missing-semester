                                                                                                       **Class one**
##1.流程：进入Linux->终端操作-> Vim-> Git-> Github

##2.目录：（1）～家目录
         （2）.当前目录
         （3）..上一级
        
##3.路径：（1）绝对路径：从/开始
         （2）相对路径：从当前位置开始
         
##4.看东西：（1）ls 看当前文件夹
           (2)cat 在终端把文件吐出
           (3)less 一页一页看
           
##5.文件和目录操作：(1)mkdir  建目录
                  (2)touch  建文件
                  (3)cp     复制
                  (4)mv     移动或重命名
                  (5)rm     删除
                  
##6.当前位置与目录切换：(1)pwd   显示当前目录
                      (2)cd:cd~  返回家目录,cd-  回到上一次目录，cd..   返回上一级
                      
##7.GIT&GITHUB:(1)协作流程：git clone 仓库地址->建分支->改代码 -> git add -> git commit -> git push ->开PR-> 合并
             (2)其他命令：git init 初始化，git status 查当前状态，git switch 切分支，git diff 查未暂存的修改
             
##8.Shell:(1)变量：eg:name="wlr"
                    echo " Hello,$ name"
        (2)重定向：eg:echo "Hello" > hello.txt(>覆盖写进；>>追加文件末尾)
        (3)管道(|):命令A|命令B(把A输出结果当成B的输入)
        (4)条件连接:A && B (A执行成功后执行B)
