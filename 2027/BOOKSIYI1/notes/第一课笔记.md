# 27赛季控制视觉招新培训第一课 课堂笔记

## 一、 Linux 基础与开发环境
1. **为什么选择 Linux (Ubuntu)**：
   * 在机器人开发和视觉领域，ROS (机器人操作系统) 和大部分视觉算法库在 Linux 下兼容性最好、部署最一致。
   * 机器人主机通常不接显示器（Ubuntu Server 无桌面环境），需要通过开发电脑（如拯救者）使用 **SSH** 远程连接进行开发和控制。
2. **文件系统路径**：
   * Linux 根目录为 `/`。路径**严格区分大小写**。
   * `~` 代表当前用户的家目录；`.` 代表当前目录；`..` 代表上一级目录。
   * **绝对路径**（从 `/` 开始）与 **相对路径**（从当前位置开始）。

## 二、 Shell 与终端操作
1. **命令结构**：`命令 [选项] [参数]`。例如 `ls -la ~/projects`。
2. **核心操作命令**：
   * 查看当前路径：`pwd`
   * 列出目录内容：`ls`（加 `-la` 查看详细信息和隐藏文件）
   * 切换目录：`cd 目录名`（`cd ..` 返回上回，`cd ~` 回家目录）
   * 创建目录：`mkdir -p`（`-p` 允许递归创建父目录）
   * 创建空文件：`touch`
   * 复制/移动/重命名：`cp` / `mv`
   * 删除文件：`rm`（**极其危险**，不进回收站，删前确认路径）
3. **Shell 进阶组合**：
   * **重定向**：`>` 覆盖写入，`>>` 追加到文件末尾。
   * **管道**：`|` 将前一个命令的输出交给下一个程序处理（如 `ls -la | grep txt`）。
   * **条件连接**：`&&` 前一条命令成功后，再执行下一条。

## 三、 Vim 编辑器
终端中常用的文本编辑器，在 SSH 和无桌面环境中必备。有“模式”之分：
1. **普通模式**：打开后的默认模式。可以移动光标、删除、复制。
2. **插入模式**：在普通模式下按 `i` 进入，此时才可以像记事本一样输入文字。按 `Esc` 返回普通模式。
3. **命令行模式**：在普通模式下输入 `:` 进入。
   * 保存退出：`:wq`
   * 强制退出不保存：`:q!`

## 四、 Git 与 GitHub 协作
1. **Git（本地版本控制）**：记录修改、查看历史。`git commit` 只保存到本地。
2. **GitHub（远程托管协作）**：托管代码库，通过 PR 讨论和评审。
3. **提交三步曲**：
   * `git add .` （把修改放入暂存区）
   * `git commit -m "修改说明"` （提交到本地仓库，**注意英文大写开头带句号**）
   * `git push` （推送到 GitHub 远程仓库）
4. **分支管理（Branch）**：为每个功能或作业建立独立的分支，互不打扰。
   * 创建并切换分支：`git switch -c 你的分支名`
5. **团队 PR 标准工作流（Fork 模式）**：
   * 在 GitHub 上 **Fork** 团队仓库到个人账号。
   * **Clone** 到本地电脑。
   * 创建 Feature 分支，在本地修改`代码。
   * **Add / Commit / Push** 推送到个人的 GitHub 远端。
   * 在 GitHub 网页上发起 **PR (Pull Request)**。
   * 等待团队 Review 评审后 Merge（合并）。

## 五、 课后任务与总结
* 完成第一次完整工作流：Fork -> Clone -> 建分支 -> 改文件 -> Commit -> Push -> 发起 PR。
* **避坑提醒**：在终端里输入密码时不显示任何字符是正常的；配置 Git 和 SSH 时确保邮箱和账号正确；`git clone` 网络不好时多试几次或使用代理。
* 学有余力：了解 catkin 与 CMake。
