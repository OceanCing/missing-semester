五、Git与GitHub的分工
-Git 用来记录文件修改历史、版本回溯、多人协作
-重点区分：`commit` 仅保存在本地电脑；`
           push`   上传远程仓库，队友才能看见

## 三层结构
1. 工作区：我们直接编辑、肉眼看见的文件
2. 暂存区：`git add` 将改动放到暂存区（准备提交）
3. 本地仓库：`git commit` 生成永久版本快照

### 基本命令
-git init
 初始化Git仓库，一个文件夹只执行一次

-git add 文件名
git add .(git add 文件名）
. 代表当前目录所有改动，加入暂存区

-git commit -m "填写本次修改备注"
 生成版本快照
坑：英文成对引号，漏写后终端出现 >，按 Ctrl+C 取消

-git status
查看状态：红色未add，绿色已add等待commit

-git log
git log --oneline
查看提交历史，--oneline 精简展示

-git diff
查看文件具体改动内容

-git restore 文件名
撤销还没add的修改，恢复到上一次commit状态

### 分支操作
-git switch -c 分支名
新建分支并且直接切换进去

-git switch 分支名
 切换到已有分支

-git branch -m 新名字
给当前分支重命名

-git merge 分支名
合并指定分支到当前分支

-git branch -d 分支名
删除本地分支

### 远程仓库命令
-git clone 仓库地址
拉取完整远程仓库到本地，clone好的仓库不用再git init

-git pull
拉取远程最新内容，同步本地，协作前建议先pull

-git push origin 分支名
将本地commit推送到远程仓库（交作业上传步骤）

-git remote -v
查看绑定的远程仓库地址


### .gitignore 文件

新建名为 `.gitignore` 的文件，告诉 Git 忽略指定文件，不追踪、不上传。
示例内容：
//*.log
//temp/
//secret.txt

注意：已经被 Git 追踪的文件，写入 ignore 无效。

### stash 储藏

临时保存改动，不 commit，方便临时切换分支

|git stash|       隐藏当前改动，工作区变干净|
|:----:|:----:|
|git stash pop |  恢复储藏的改动|

### PR（Pull Request）提交

push 到自己分支之后，在仓库网页端新建 PR。
作用：通知管理员审核内容，请求合并进主分支 main，审核通过才合并。
