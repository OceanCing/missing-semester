# Linux 与 Git/GitHub 学习笔记

## 上一节课

主要学习了 Linux 的概念、Shell 与 Vim 指令，以及 GitHub。

- Linux 可以通过发送申请，再由内核决定通过或拒绝。
- 可以通过 SSH 连接并控制开发电脑。
- Linux 的目录通过 `.` 和 `/` 连接。

## Shell 与 Vim

### Shell 指令

- Shell 指令由 **命令 + 选项 + 参数** 构成。
- 常用指令：
  - `pwd`
  - `ls`
  - `cd`
  - `mkdir`：创建文件夹
  - `touch`：创建文件
  - `cp`
  - `mv`
  - `rm`：一般用于删除文件；加上 `-r` 可以移除文件夹
  - `cat`：查看文件内容；配合 `| grep` 可以查找文字所在当前具体行的内容

### Shell 的组合

- 变量可以保存后再引用。
- `echo` 可以重定向，即覆写文件或增加文件内容。
- 管道：左边命令运行后输出的内容进入管道，再在管道中运行右边的命令。
- `&&` 用于连接指令。

### Shell 快捷操作

- `ls` 可以快速查找。
- `Tab` 可以补全。
- 上、下方向键可以调出历史指令。

### Vim 编辑器

- Vim 可以在终端中编辑配置文件。
- 使用方式：在终端中输入 `vim txt`。
- 常用按键：
  - `h`、`j`、`k`、`l`：移动光标
  - `dd`：删除当前行
  - `yy`：复制当前行
  - `u`：撤销
  - `/word`：查找 `word`
- 常用命令：
  - `:w`：保存
  - `:q`：退出
  - `:q!`：放弃修改并退出

## Git 与 GitHub

- Git 用于本地控制文件。
- GitHub 是远端托管仓库。
- 可以通过 SSH 进行远端认证，并完成提交、拉取等操作。

### 常用 Git 命令

- `git add`：增加文件
- `git commit`：暂存，记录本地提交
- `git clone <文件地址>`：下载
- `git status`：查看当前分支
- `git diff`：查看未暂存的修改
- `git switch`：创建分支或切换分支
- `git pull`：拉取
- `git push`：推送到远端
