## linus目录：

～：表示家目录 （主目录） /home/名字  这个文件夹里面的内容
/：根目录：/home/这个最高级目录
/etc  ：存放系统内容
/user：存放程序和库（bin：存放一些二进制文件；home：系统相关文件）
/var：存放日志等可变数据
/dev：设备文件
/home/user/：绝对路径，从/开始引导
./hello.txt：相对路径，表示从当前所在目录开始引导
～/ <文件名/> ：表示家目录下的某个文件

## shell运行：

1. 在终端里面，用户输入命令
2. shell运用解释命令
（有bash和Zsh两种方法，*但一般用得更多的是bash*）
3. 再运行到程序之中

## 创建文件并记录的流程：

1. mkdir+目录名字：创建新目录
2. touch+文件名字（txt/c/cpp/...）：创建新文件
3. vim+文件名字：进行编辑文件（进入）
4. git 管理（add等等）

## shell命令：

- ls：查看当前目录内容
- -la：（-l：以长文件格式显示）（a：显示隐藏文件）
- ～/<文件名/>：操作哪个文件
- cd：进入某个文件
- cd..：返回上一级
- cd～：返回家目录
- cd+目录名字：返回指定目录
- pwd：显示当前的目录名字
- mkdir -p：
目录不存在时：自动创建一个
目录存在时：也不会冲突
- cp ：复制文件
格式：
cp 要复制的文件名字+格式 生成的文件名+格式
- mv：移动或者重命名：
格式：
mv 要移动的文件名字+格式  :  移动到的位置/重命名的文件名字+格式
（后面的名字如果有重复就是*覆盖*，如果无就是*移动*到那个位置）
- rm删除文件
**不进入回收箱，删除需要谨慎**
- cat/less：直接查看/分类查看

## git和github：

- git：记录每次修改内容和记录，新功能创建分支
- github：git仓库管理，通过PR讨论和评审，合并团队认可地修改

### git流程：

'''
工作区---暂存区---本地仓库---github远程仓库
'''

1. git add
2. git commit（记录到本地仓库）
3. git push  （远程发送）

*首次使用git需要提交/上传自己的姓名和邮箱地址*
格式：
git config --global user.name"<自己的名字/>"
git config --global user.email"<邮箱地址/>"

提交作者信息后还需要ssh认证：远程提交权力
ssh认证有公钥和私钥，公钥是要和github账号绑定的，***私钥是不可以流露给人看的（系统安全）***

### git相关语法：

- git clone +仓库地址：下载仓库和历史记录
- git status：查看当前分支和状态
- git diff：查看还没有暂存的修改
- git log--online：以简短格式查看提交历史
- git switch -c feature/hello：创建并切换到功能分支（hello是创建的名字）
- git add hello.txt：暂存hello文件
- git commit -m“Add greeting”：
记录一次本地提交-m “表示这次修改说明的注释”
- git push -u origin feature/hello：把hello文件远程推送到origin仓库中并建立追踪对象
下一次就可以直接用git pull拉取或者git push，省略文件名字
- git pull：获取并整合当前分支的更新
- git switch main：切回主分支
分支与主分支不会相互冲突，并存

## 团队PR流程：
fork仓库到本地仓库--git clone内容--新建feature分支--自己修改（add/commit）--git push--个人fork并提交--上传pr--审核--合到团队仓库

## shell sh脚本

代码创建之后需要先写
#! /bin/bash

-  先告诉操作系统用 */bin/bash*解释器来运行当前脚本


## time=$(date +"%Y-%m-%d %H:%M:%S")
---
解释：
- $()：把括号里面的数值，赋值给前面的变量
- date "+%Y-%m-%d %H:%M:%S"
- %Y：四位数字的年份
- %m：月份
- %d：日
- %H：小时
- %M：分
- %S：秒

## cmd=$(history | tail -n 10)
*使用history 需要先在一开始写：*
set -o history 
---
解释：
-  history：列出终端敲过的命令
-  | 把左边的输出传送给右边
- tail -n 10：tail意思为看文件末尾， -n 10意思是看十条
**不过只能用在写sh的文档里面提到的语法**

要查询之前在终端的记录的话：
cmd=$（tail -n 10 ~/.bash_history）

if：判断路径是否存在
