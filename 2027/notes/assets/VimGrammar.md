#       		  Vim 编辑器快捷键速查笔记

一、 模式切换与基础操作
--------------------------------------------------

Esc        : 返回普通模式（必记！打字前/执行命令前按）
i          : 在光标前进入插入模式（Insert）
a          : 在光标后进入插入模式（Append）
o          : 在光标下方新建一行并进入插入模式
O          : 在光标上方新建一行并进入插入模式
v          : 进入可视模式（字符选择）
V          : 进入可视模式（整行选择）
Ctrl + v   : 进入可视块模式（矩形选择，可批量注释）
:          : 进入命令行模式（在屏幕底部输入命令）

--------------------------------------------------
二、 光标移动（普通模式下）
--------------------------------------------------
h / j / k / l  : 左 / 下 / 上 / 右（方向键也可，但不推荐）
w              : 移动到下一个单词的开头
b              : 移动到上一个单词的开头
e              : 移动到下一个单词的结尾
0 (数字0)      : 移动到本行的绝对开头
^              : 移动到本行的第一个非空白字符
$              : 移动到本行的末尾
gg             : 移动到文件第一行
G              : 移动到文件最后一行
:行号          : 跳转到指定行（例如 :10 跳转到第10行）
Ctrl + f       : 向下翻页（Forward）
Ctrl + b       : 向上翻页（Backward）
Ctrl + d       : 向下滚动半页
Ctrl + u       : 向上滚动半页
%              : 跳转到匹配的括号 ( ) [ ] { }

--------------------------------------------------
三、 编辑与修改
--------------------------------------------------
x              : 删除光标所在处的单个字符
X              : 删除光标前的一个字符
dd             : 删除（剪切）当前行
数字 + dd      : 删除（剪切）多行，如 3dd 删除3行
dw             : 删除光标所在位置到下一个单词开头
d$             : 删除光标位置到本行末尾
yy             : 复制当前行
数字 + yy      : 复制多行，如 3yy 复制3行
p              : 在光标后（下方）粘贴
P              : 在光标前（上方）粘贴
u              : 撤销上一次操作（Undo）
Ctrl + r       : 重做（取消撤销，Redo）
r              : 替换当前字符（按 r 后再按新字符）
cw             : 删除当前单词并进入插入模式（Change Word）
cc             : 删除当前行并进入插入模式
. (点号)       : 重复上一次的修改操作（极其强大的快捷键）

--------------------------------------------------
四、 查找与替换
--------------------------------------------------
/word          : 向下查找 "word"（按 n 找下一个，N 找上一个）
?word          : 向上查找 "word"
n              : 重复上一次查找（同方向）
N              : 反向重复上一次查找
:%s/old/new/g  : 全文替换 old 为 new
:10,20s/a/b/g  : 将第10行到第20行的 a 替换为 b
:s/old/new/g   : 仅替换当前行

--------------------------------------------------
五、 保存与退出（命令行模式）
--------------------------------------------------
:w             : 保存文件（Write）
:q             : 退出（Quit），未保存会报错
:wq            : 保存并退出（最常用）
:x             : 保存并退出（同 :wq，但只在有修改时保存）
:q!            : 强制退出，不保存修改
ZZ             : (普通模式) 保存并退出
:e!            : 放弃修改，重新加载原文件

--------------------------------------------------
六、 可视模式下的操作
--------------------------------------------------
先按 v / V / Ctrl+v 进入可视模式，选中内容后：
y              : 复制选中内容
d              : 删除选中内容
> 或 <         : 向右 / 向左缩进
> ~              : 切换选中内容的大小写
> J              : 将选中行合并为一行

--------------------------------------------------
七、 窗口与标签页（进阶）
--------------------------------------------------
:sp 文件名     : 水平分屏
:vsp 文件名    : 垂直分屏
Ctrl + w + w   : 在分屏窗口之间切换
:tabnew        : 新建标签页
gt / gT        : 切换到下一个 / 上一个标签页

--------------------------------------------------
八、 常用设置命令（可在命令行模式输入）
--------------------------------------------------
:set nu        : 显示行号（number）
:set nonu      : 隐藏行号
:syntax on     : 开启语法高亮
:set hlsearch  : 开启搜索结果高亮
:set nohlsearch: 关闭搜索高亮
:set tabstop=4 : 设置 Tab 键为 4 个空格
:set expandtab : 将 Tab 自动转换为空格

--------------------------------------------------
九、 帮助与学习
--------------------------------------------------
:help          : 打开内置帮助文档
:help 关键词   : 查看具体命令的帮助（如 :help dd）
(在终端输入) vimtutor : 打开官方交互式教程
