| 一些常见的路径 | 这些路径的具体含义 |

## SSH 密钥

如果 SSH 密钥是在 `rm_ros` 容器里生成的，宿主机 `~/.ssh` 里没有，将会导致 `git clone` 报 `Permission denied (publickey)`。

### 1) 把容器里的密钥装到宿主机

```bash

docker cp rm_ros:/root/.ssh/id_ed25519     ~/.ssh/id_ed25519
docker cp rm_ros:/root/.ssh/id_ed25519.pub ~/.ssh/id_ed25519.pub
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub
```


## 散装内容

- 整数：`int`
- 整数、小数：`double`

`unsigned` 和 `int` 之类的组合使用使得数据只有 0 和正数，但是不能和 `double` 以及 `float` 组合使用。如果想要打印 unsigned 类型的话，那么需要 `%u` 作为占位符。而 `signed` 则是有符号，即有正负。

整数类型存储字节容量大小的排序：

`char < short < int < long < long long`

具体字节数通常如下（1 字节 = 8 位）：

1. `char`：1 字节
2. `short`（或 `short int`）：2 字节
3. `int`：4 字节
4. `long`（或 `long int`）：4 字节（Windows 系统）或 8 字节（Linux/macOS 64 位系统）
5. `long long`（或 `long long int`）：8 字节
6. `float` 占 4 字节
7. `double` 占 8 字节

浮点型补充：

1. 浮点型常量共有 3 种类型：`float`、`double`、`long double`
2. 存储字节容量大小排序为：`float < double < long double`
3. 输入时没有前缀；浮点常量的后缀是 `f`/`F`、`l`/`L`
4. 保留 2 位小数不是"前缀"，而是格式控制符，在 `printf` 中通常用 `%.2f` 表示

固定保留

```c
float a = 3.1415926;

printf("%.3f\n", a);  // 输出 3.142（保留3位，自动四舍五入）
printf("%.5f\n", a);  // 输出 3.14159（保留5位）
```

取值范围：

`double > float > long long > long > int > short > char`

`||` 以及 `&&` 可以在 printf 中多次在一个语句中使用。

取余的时候前后都要是整数才行。

指针变量的名字：例如 `int *p = &a`，那么指针变量的名字是 `p`。

并且，这个时候 `*p` 整体就代表了 `a` 的值，例如 `a = 1`，那么 `*p` 就是 1。而单单一个 `p` 则是代表了 `a` 的地址。

- `x64` 是六十四位编译器
- `x86` 是三十二位编译器

想要让函数赋予指针的值维持到程序结束，需要加上 `static`。

指针相减获取步长的时候，不需要在前面加上 `*`。

`*` 配合 `%p` 使用获取内存地址，而不加 `*` 时则是直接和 `%d` 配合获取数据大小。

`int *p1 = arr` 与 `int *p1 = &arr`：前者仅仅代表数组首位索引，后者代表整个数组，虽然获取地址时二者输出结果一致，但是后者的步长是整个数组。

只读常量区定义的字符串可以复用，但造成了复用后存储地址不发生改变的情况。

`scanf` 一个数组名的时候，无需 `&`。

要求键盘录入字符串时，必须要使用数组定义，不得使用指针。

在 Windows 中，一个中文占两个字节。

使用 `strcat` 的时候需要注意一些问题，详情见相册黑马程序员视频

## 内存分配示例

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;
    scanf("%d", &n);

    int *a = (int*)malloc(n * sizeof(int)); // 动态分配 n 个 int
    if (a == NULL) {
        return 1;
    }

    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }

    free(a);
    return 0;
}
```

`a++` 和 `++a`：如果代码只有单独一行用到单独的 `a++` 或 `++a`，那么效果一致。

## 使用指针？为什么
1. 有些时候，我们想要使用函数来交换两个数的数值大小，但是我们仅仅只能将两个数的值输入函数，函数的运行不会使得函数外的两个值大小发生变化。因此，我们使用指针传入地址，这样就可以做到修改函数外这两个值的大小。
2. 当使用函数，并且我们需要函数返回值大于一时就需要用到指针，例如用函数找出数组中的最大值、最小值并将他们输出。
3. 例如在除法程序，我们需要用到函数的返回值（0，1）判断是否能够执行（比如不能除以 0），同时我们要输出结果，那么就要用到指针。


## 指针和数组的一些关系
指针可以当数组：`*p` 和 `p[0]`。

数组可以当指针：`a[0]` 和 `*a`。

数组变量是 const 的指针、常量指针，不能与别的数组之间互相赋值。
