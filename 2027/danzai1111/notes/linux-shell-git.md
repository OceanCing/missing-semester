#第一课笔记

##linux命令

- 'pwd':显示当前位置  --在哪
- 'ls = list':显示当前位置目录和文件  --有什么
- 'ls -la':显示隐藏信息
- 'cd':切换目录
- 'mkdir':创建目录
- 'touch':创建空文件
- 'cp = copy':复制
- 'mv = move':移动  --可以用来重命名
- 'cat':看文件内容
- 'less':分页看内容
- 'rm = remove':删除  --删了不能恢复

##shell
shell是人与linux之间的媒介，作用是解释我所输入的指令如pwd，cd等等
shell脚本可以执行多条命令

###shell符号

- '>':写入文件并且覆盖原文件内容
- '>>':写入文件并追加到结尾
- '|':将一个命令的输出传给下一个命令
- '$0':指脚本的名字或路径 

##vim
- vim是一种文本编辑器，可以在终端中使用（vim 文件  即可打开）
- 常用于SSH和无桌面环境中的配置，代码编辑（SSH指远程登陆另一台电脑）
- 可以切换模式
1. 普通模式:移动，删除，复制
  - 'h j k l'对应"上 下 左 右"
  - 'dd'意为删除当前行
  - 'yy'为复制。。。
  - 'p'为粘贴。。。
  - 'u'为撤销
  - '/word'为搜索word
  - :w保存  :q退出  :wq保存退出  :q!放弃修改退出
2. 插入模式:输入文本（输入i进入，Esc返回）
3. 命令行:保存，退出

##git
可以记录本地修改，提交记录，方便查看历史，还能为原有项目创建分支

###git常用命令
- git clone<仓库地址>    下载仓库及提交历史（下载github上的远程仓库）
- git ststus             查看当前分支和文件状态（是否发生修改）
- git diff               查看尚未暂存的修改（add后修改的内容会进入暂存区）
- git log --oneline      简洁查看提交历史
