# Linux、Vim && Shell、Git && GitHub

## Linux 

### 1. 目录结构与路径

| 分类           | 内容         | 说明                                               |
| -------------- | ------------ | -------------------------------------------------- |
| **常见目录**   | `/`          | 根目录（所有目录的起点）                           |
|                | `/home/user` | 用户文件                                           |
|                | `/etc`       | 系统配置                                           |
|                | `/usr`       | 程序与库                                           |
|                | `/var`       | 日志等可变数据                                     |
|                | `/dev`       | 设备文件                                           |
| **特殊路径符** | `~`          | 当前用户的家目录 (home)                            |
|                | `.`          | 当前目录                                           |
|                | `..`         | 上一级目录                                         |
| **路径表示**   | 绝对路径     | 从 `/` 开始（如 `/home/user/example`），大小写敏感 |
|                | 相对路径     | 从当前位置开始（如 `./hello.txt`）                 |

### 2. 终端、Shell 命令

| 概念         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **层级关系** | Terminal (终端/输入输出界面) -> Shell (Bash/Zsh，解释命令) -> 程序/系统 |
| **命令结构** | `命令 [选项] [参数]` *示例：`ls -la ~/projects`*             |
|              | **命令** `ls`：做什么                                        |
|              | **选项** `-la`：怎样执行（`-l`详细信息，`-a`含隐藏项）       |
|              | **参数** `~/projects`：操作对象                              |

### 3. 常用命令

| 命令         | 作用                        | 示例                                                         |
| ------------ | --------------------------- | ------------------------------------------------------------ |
| `pwd`        | 显示当前目录                | `pwd`                                                        |
| `ls`         | 列出目录内容                | `ls`                                                         |
| `cd`         | 切换目录                    | `cd example` (进入指定目录) `cd ..` (返回上一级) `cd ~` (返回家目录) |
| `mkdir -p`   | 创建目录，允许补齐父目录    | `mkdir -p ~/linux_demo`                                      |
| `touch`      | 创建空文件或更新时间        | `touch hello.txt`                                            |
| `cp`         | 复制文件                    | `cp hello.txt hello-copy.txt`                                |
| `mv`         | 移动或重命名                | `mv hello-copy.txt backup.txt`                               |
| `rm`         | 删除文件                    | `rm backup.txt`                                              |
| `cat / less` | 直接查看 / 分页查看文件内容 | `cat hello.txt`                                              |

### 4. Shell 四种常用组合

| 组合类型     | 语法/示例                                              | 作用说明                             |
| ------------ | ------------------------------------------------------ | ------------------------------------ |
| **变量**     | `name="RM"` `echo "$name"`                             | 保存一个值，再通过变量引用它         |
| **重定向**   | `echo "hello" > hello.txt` `echo "hello" >> hello.txt` | `>` 覆盖写入；`>>` 追加到文件末尾    |
| **管道**     | `ls -la | grep txt`                                    | 将前一个命令的输出交给下一个程序处理 |
| **条件连接** | `mkdir -p demo && cd demo`                             | 前一条命令成功执行后，再执行下一条   |



## Vim

### 1. 模式切换

| 模式           | 进入方式                       | 用途                   |
| -------------- | ------------------------------ | ---------------------- |
| **普通模式**   | 默认模式 (按 `Esc` 可随时返回) | 移动光标、删除、复制等 |
| **插入模式**   | 普通模式下按 `i`               | 输入文本               |
| **命令行模式** | 普通模式下按 `:`               | 保存、退出、搜索替换等 |

### 2. 必备快捷键 (普通模式)

| 按键      | 操作                   |
| --------- | ---------------------- |
| `h j k l` | 左、下、上、右移动光标 |
| `dd`      | 删除当前行             |
| `yy`      | 复制当前行             |
| `p`       | 粘贴                   |
| `u`       | 撤销                   |
| `/word`   | 搜索 word              |

### 3. 常用退出命令 (命令行模式)

| 命令  | 操作           |
| ----- | -------------- |
| `:w`  | 保存           |
| `:q`  | 退出           |
| `:wq` | 保存并退出     |
| `:q!` | 放弃修改并退出 |



## Git &GitHub

### 1. 获取与查看命令

| 命令                   | 作用                   |
| ---------------------- | ---------------------- |
| `git clone <仓库地址>` | 下载仓库及提交历史     |
| `git status`           | 查看当前分支和文件状态 |
| `git diff`             | 查看尚未暂存的修改内容 |
| `git log --oneline`    | 用简短格式查看提交历史 |

### 2. 分支与提交命令

| 命令                           | 作用                         |
| ------------------------------ | ---------------------------- |
| `git switch -c feature/hello`  | 创建并切换到功能分支         |
| `git add hello.txt`            | 暂存指定文件                 |
| `git commit -m "Add greeting"` | 记录一次本地提交             |
| `git push -u origin dev-zkz`   | 推送到远程并建立跟踪关系     |
| `git switch main`              | 切回主分支                   |
| `git pull`                     | 获取并整合当前分支的远程更新 |
