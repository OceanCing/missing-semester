# C语言（备忘）

* printf（“”）中`%%` 输出表示一个 `%` 字符 故

printf("%d==%%====d===%d\n",a,b,e)      输出     a%d=b（%%输出一个% 第二个d输出为字符d 第三个d继承b的值）

printf("%d%%%d=%d\n",a,b,e)   输出    a%b=e

* scanf(%d/%f/%lf/%c,&a);输入
* 倒数第二行getchar（）避免输入残留
* = 赋值  ==相等
* 初始化语句不能连续赋值
  int a=b=c=10 是错的
  a=12
  a+=a-=a*a
  a=-264
  注：运算中a是随时变化的 
* 关键：逗号表达式的值为逗号最后一个表达式n的值
  表达式计算时无说明则四舍五入 整数运算得整数
  空语句 while（getchar（）！= \n）;
  表示函数体为空
* \t空八位
* 输入scanf double型数据（小数）是用%lf
  输出时使用%f
* 判断表达式中最终得出值1或0 其中步步分开计算
  如3>2>1的返回值是0 因为3>2成立 返回值1
  1>1不成立 返回值为0 总表达式的返回值为0
* 注意运算符的优先级
* 运算量非0即为真
  表达式1才是真
