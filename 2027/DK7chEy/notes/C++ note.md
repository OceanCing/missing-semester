#### 5.switch控制语句

* 基本形式：

  switch（==常量表达式==，且类型应当为==整型==）

  {

  ==case==  常量表达式1：

   code 1；

   ==break==；（可选）

  case  常量表达式2：

   code 2；

   break；（可选）

  ……

  case  常量表达式n：

   code n；

   break；（可选）

  ==default==（可选）：

   code；

  }

* 含义（类比if else语句）：

  1.若case后的常量表达式的==值==与switch的常量表达式的==值==相等 则执行该case后（以及——之后所有case后,包括default后）的代码，直到遇到break

  2.break表示若该case的代码执行 则整个switch语句在此停止 否则继续

  3.default表示若所有case都不符合switch 则执行default后的代码（无default则直接停止）

* 常见情景：要将一个值与很多值进行匹配判断是否一致并进行相应动作时
