## 一、 Linux
- 文件路径：
- `/`：根目录
- `~`：用户家目录
- `.`：当前目录
- `..`：上一级
- 注： Linux路径大小写敏感
## 二、 Shell终端常用命令
1. 命令格式：“命令 选项 参数”（ls ,-la ,~/project）
2. 目录操作：
- `pwd` : 查看当前所在路径
- `ls` : 列出目录文件
- `ls -la` : 查看全部详细信息
- `cd 目录名` : 切换目录
- `cd ..` : 返回上一级
- `mkdir -p` : 创建多级目录
- `touch` : 创建空文件
- `cp` : 复制
- `mv` : 移动或重命名
- `rm` : 删除（没有回收站，操作要谨慎！）
- `cat/less` : 直接查看/分页查看
3. 常用组合：
- 变量 : 保存一个值，用变量引用（例 ：name="RM" echo"$name" ）
- 重定向 : > 覆盖写入 ; >> 追加到文件末尾
- 管道 `|` : 将输出交给下一个程序
- 条件连接 `&&` : 前一条成功后再执行下一条
- `ls --help` : 快速查看帮助
- `man ls` : 查看完整手册，按 `q` 退出
## 三、Vim编辑器
- 普通模式 : 移动光标、删除复制； 按 `i` 进入插入模式
- 插入模式 : 输入文字； 按 `Esc` 回到普通模式
- 普通模式输入 : `:wq` 保存并退出； `:q!` 放弃修改强制退出
## 四、Git与GitHub协作
1. Git : 本地版本控制 ; GitHub : 远程托管仓库 
2. commit只记录到本地仓库 ； push才把提交发送到远程
3. SSH: 私钥保存在本机 , 公钥上传GitHub， 实现免密码推送
4. Fork-PR 流程：Fork团队仓库 -> clone本地 -> 新建开发分支 -> push到自己fork仓库 -> 发起Pull Request给原仓库
