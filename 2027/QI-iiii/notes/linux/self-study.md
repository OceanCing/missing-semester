路径和终端

/：根目录  
~：当前用户的家目录  
.：当前目录  
..：上一级目录  
绝对路径：从 / 开始  
相对路径：从当前目录开始  
↑ / ↓：翻找历史命令  
Tab：补全命令或路径  
Ctrl + C：中断当前命令  
Ctrl + L / clear：清屏  
命令 --help / man 命令：查看用法，按 q 退出


文件和目录

pwd：查看当前目录  
cd 目录：进入目录  
cd ..：返回上一级  
cd ~ / cd：返回家目录  
cd -：回到上一次所在目录  
ls：列出目录内容  
ls -a：包括隐藏文件  
ls -l：显示详细信息  
ls -h：文件大小显示为易读单位，通常配合 -l  
cat 文件：直接查看文件内容  
mkdir 目录：创建目录  
mkdir -p a/b：同时创建缺少的父目录  
touch 文件：创建空文件或更新时间  
cp 来源 目标：复制文件  
cp -r 来源目录 目标目录：复制目录  
mv 来源 目标：移动或重命名  
rm 文件：删除文件  
rm -r 目录：连同目录内容一起删除  
rmdir 目录：删除空目录

查看和编辑

more 文件：分页查看，往下翻  
less 文件：分页查看，可上下翻和搜索，按 q 退出  
head 文件：看开头几行  
tail 文件：看结尾几行  
tail -f 文件：持续查看新追加的内容  
vim 文件 / nano 文件：编辑文件

Shell 符号

echo 内容：输出内容  
sleep 秒数：等待指定秒数  
*：匹配任意数量的字符  
?：匹配一个字符  
[abc]：匹配方括号中任意一个字符  
> 文件：覆盖写入标准输出  
>> 文件：追加标准输出  
2> 文件：覆盖写入错误信息  
< 文件：从文件读取输入  
命令1 | 命令2：把前一条命令的输出交给后一条  
命令1 ; 命令2：依次执行  
命令1 && 命令2：前一条成功才继续  
命令1 || 命令2：前一条失败才继续  
name="Linux" / echo "$name"：赋值和读取变量  
'内容'：内容按原样处理  
"内容"：其中的变量仍可展开  
\：转义后面的特殊字符

用户和权限

whoami：查看当前用户名  
id：查看用户和组的编号  
groups：查看所属用户组  
passwd：修改密码  
su 用户名：切换用户  
sudo 命令：临时用管理员权限执行  
ls -l：查看文件权限、所有者和所属组  
chown 用户:组 文件：修改所有者和所属组  
chmod 权限 文件：修改读、写、执行权限  
chmod +x 文件：增加执行权限

软件与远程

sudo apt update：刷新软件包列表  
sudo apt install 包名：安装软件  
apt search 关键词：搜索软件包  
sudo apt upgrade：升级已安装的软件包  
sudo apt remove 包名：卸载软件  
sudo apt purge 包名：卸载软件并清除配置  
sudo apt autoremove：清理不用的依赖  
ssh 用户名@主机：连接远程主机  
scp 来源 目标：在本机和远程主机之间复制文件

下载和压缩

wget 地址：下载文件  
wget -O 文件名 地址：指定保存名称  
wget -c 地址：断点续传  
curl -L -O 地址：跟随跳转并下载文件  
curl -L -o 文件名 地址：指定保存名称  
aria2c 地址：下载文件  
tar -cvf 包名.tar 目录：打包  
tar -xvf 包名.tar：解包  
tar -cvzf 包名.tar.gz 目录：打包并用 gzip 压缩  
tar -xvzf 包名.tar.gz：解压  
zip -r 包名.zip 目录：压缩  
unzip 包名.zip：解压  
7z a 包名.7z 目录：压缩  
7z x 包名.7z：解压

文本和链接

wc 文件：统计行数、单词数、字节数  
wc -l 文件：统计行数  
wc -w 文件：统计单词数  
wc -m 文件：统计字符数  
grep 内容 文件：搜索包含指定内容的行  
grep -n 内容 文件：显示行号  
grep -r 内容 目录：递归搜索  
sed 's/旧/新/g' 文件：输出替换后的内容  
sed -i 's/旧/新/g' 文件：直接修改原文件  
ln -s 原路径 链接名：创建软链接  
ln 原文件 链接名：创建硬链接

任务和系统状态

命令 &：启动后台任务  
Ctrl + Z：暂停前台任务  
bg：让暂停的任务在后台继续  
fg：把后台任务切回前台  
jobs：查看当前终端的后台任务  
nohup 命令 &：终端断开后继续运行  
screen / tmux：复用终端会话  
top / htop：查看进程和资源占用  
kill 进程号：结束指定进程  
pkill 进程名：按名字结束进程  
du -sh 目录：查看目录占用空间  
df -h：查看文件系统剩余空间  
lsblk：查看磁盘和分区  
iotop：查看磁盘读写进程  
ifconfig / ip addr：查看网卡和地址  
iftop：查看连接的网络流量  
nload：查看网卡收发速度  
mount 设备 挂载点：挂载设备  
umount 挂载点：卸载挂载

环境和其他

env：查看环境变量  
export 变量名=值：设置环境变量  
echo $PATH：查看命令搜索路径  
which 命令：查看命令所在位置  
source ~/.bashrc：让当前终端读取修改后的配置  
watch 命令：定时重复执行  
命令 | tee 文件：同时显示结果并写入文件  
diff -u 旧文件 新文件：比较文件差异  
uname -a：查看内核与系统架构信息  
cat /etc/os-release：查看发行版信息  
Ctrl + S / Ctrl + Q：暂停 / 恢复终端输出
