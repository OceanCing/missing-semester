Vim

三种模式：

普通模式
刚进入 Vim 默认就是普通模式
用于移动光标、删除、复制、粘贴等


输入模式
用于输入文字
从普通模式进入
i 光标前插入
a 光标后插入
按 Esc 回到普通模式


可视模式
用于选中文本
v 按字符选择
V 按行选择
Ctrl + v 按列选择



移动与编辑

移动：
h 左
j 下
k 上
l 右

单词移动：
w 到下一个单词开头
b 到上一个单词开头
e 到当前或下一个单词结尾

行内移动：
0 到行首
^ 到本行第一个非空字符
$ 到行尾
文件移动
gg 到文件开头
G 到文件结尾
nG 到第 n 行

查找字符：
f字符 跳到该字符上
t字符 跳到该字符前
; 重复上一次查找
, 反向重复查找
次数可以写在命令前
3w 往后跳 3 个单词

删除：
x 删除当前字符
dd 删除当前行
D 删除到行尾
dw 删除到下一个单词开头

修改：
r 修改一个字符
cw 修改一个单词
cc 修改整行
C 修改到行尾
修改后会自动进入插入模式

复制粘贴：
yy 复制当前行
yw 复制一个单词
p 在光标后粘贴
P 在光标前粘贴
撤销重做
u 撤销
Ctrl + r 重做
操作符可以和移动命令组合
d + w = dw
y + $ = y$


文本对象操作
文本对象就是把一个完整的内容看成整体

i 表示 inside，不包括两边符号
a 表示 around，包括两边符号

单词
diw 删除当前单词
ciw 修改当前单词
yiw 复制当前单词

引号内容
di" 删除双引号里面的内容
ci" 修改双引号里面的内容
da" 连双引号一起删除

括号内容

di( 删除小括号里面内容
ci{ 修改花括号里面内容
va[

常用的对象
w 单词
" 单引号或双引号
( ) 小括号
[ ] 中括号
{ } 大括号


寄存器与宏

寄存器可以理解为多个剪贴板,平常复制删除的内容默认放在无名寄存器

指定寄存器用 "字母
"ayy       复制当前行到 a 寄存器
"ap        粘贴 a 寄存器内容

宏就是录制一串操作，后面重复执行
qa         开始录制到 a 寄存器
q          停止录制
@a         执行 a 宏
@@         重复上一次宏
数字@a 可以连续执行多次
(批量改相同位置时，宏比重复手动操作快)

列操作
Ctrl + v 进入列选择
选中多行后按 I 在每行前面同时插入
选中多行后按 A 在每行后面同时追加
输入完成后按 Esc 生效


命令模式

普通模式下输入 : 进入命令模式

文件操作
:w 保存
:q 退出
:q! 强制退出不保存
:wq 保存并退出
:e 文件名 打开文件

搜索
/内容 往后搜索
?内容 往前搜索
n 下一个结果
N 上一个结果

替换
:s/旧/新/        替换当前行第一个
:s/旧/新/g       替换当前行全部
:%s/旧/新/g      替换全文全部

分屏
:sp 文件名 水平分屏
:vsp 文件名 垂直分屏
Ctrl + w 后接 h j k l 切换窗口

显示行号
:set number
:set nonumber
