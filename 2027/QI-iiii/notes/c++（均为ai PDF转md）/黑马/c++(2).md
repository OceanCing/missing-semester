1. 内存分区模型

程序运行前，内存分为代码区和全局区，程序运行后才会有栈区和堆区

① 代码区

存放 CPU 执行的机器指令

特点：共享、只读

共享：频繁被执行的程序只需要在内存中有一份代码

只读：防止程序意外修改自己的指令

② 全局区

全局变量、静态变量、常量都放在全局区

全局区的数据在程序结束后由操作系统释放

```cpp
int g_a = 10;        // 全局变量
static int s_a = 20; // 静态变量
const int c_a = 30;  // 常量
```

③ 栈区

由编译器自动分配释放，存放函数的参数值、局部变量等

注意：不要返回局部变量的地址，函数执行完局部变量就被释放

```cpp
int *func()
{
    int a = 10;
    return &a;
}

int main()
{
    int *p = func();
    cout << *p << endl;
}
```

④ 堆区

由程序员分配释放，若程序员不释放，程序结束时由操作系统回收

在 C++ 中主要利用 `new` 在堆区开辟内存

```cpp
int *func()
{
    int *p = new int(10);
    return p;
}

int main()
{
    int *p = func();
    cout << *p << endl;

    delete p;
    p = NULL;
}
```

用 `new` 创建数组

```cpp
int *arr = new int[10];

delete[] arr;
arr = NULL;
```

2. 引用

给变量起别名

① 引用的基本语法

```cpp
数据类型 &别名 = 原名;

int a = 10;
int &b = a;

b = 20;
cout << a << endl; // 20
```

② 引用的注意事项

1. 引用必须初始化

2. 引用在初始化后，不可以改变指向

```cpp
int a = 10;
int b = 20;

int &ref = a;
ref = b; // 赋值操作，不是改为引用 b
```

③ 引用做函数参数

引用传递时，形参会修改实参，效果和地址传递相同

```cpp
void swap(int &a, int &b)
{
    int temp = a;
    a = b;
    b = temp;
}

int main()
{
    int a = 10;
    int b = 20;

    swap(a, b);
    cout << a << endl;
    cout << b << endl;
}
```

④ 引用做函数返回值

不要返回局部变量的引用

函数调用可以作为左值

```cpp
int &test()
{
    static int a = 10;
    return a;
}

int main()
{
    int &ref = test();
    cout << ref << endl;

    ref = 100;
    cout << test() << endl;
}
```

⑤ 引用的本质

本质上是一个指针常量，指针的指向不可修改

```cpp
int a = 10;
int &ref = a;

// 编译器转换为 int *const ref = &a;
```

⑥ 常量引用

```cpp
int a = 10;
const int &ref = a;

// ref = 20;  不可以修改
```

常量引用可以给字面量取别名

```cpp
const int &ref = 10;
```

通常用于函数形参，既可以减少拷贝，又可以防止误修改数据

```cpp
void showValue(const int &val)
{
    cout << val << endl;
}
```

3. 函数提高

① 函数默认参数

函数形参可以有默认值，调用时没有传入数据就使用默认值

```cpp
int func(int a, int b = 20, int c = 30)
{
    return a + b + c;
}

int main()
{
    cout << func(10) << endl; // 60
}
```

注意：有默认值的参数必须从右往左连续设置

声明和定义只能有一个位置写默认参数

```cpp
int func(int a, int b = 20);
int func(int a, int b)
{
    return a + b;
}
```

② 函数占位参数

```cpp
void func(int)
{
    cout << "func" << endl;
}

int main()
{
    func(10);
}
```

占位参数也可以有默认值

```cpp
void func(int a, int = 10)
{
    cout << a << endl;
}
```

③ 函数重载

函数名相同，可以提高复用性

满足条件

1. 在同一个作用域下

2. 函数名称相同

3. 函数参数类型不同，或者参数个数不同，或者参数顺序不同

```cpp
void func()
{
    cout << "func()" << endl;
}

void func(int a)
{
    cout << "func(int)" << endl;
}

void func(double a)
{
    cout << "func(double)" << endl;
}
```

函数的返回值不可以作为函数重载的条件

```cpp
// int func(int a);
// double func(int a);  错误
```

引用作为重载条件

```cpp
void func(int &a)
{
    cout << "普通引用" << endl;
}

void func(const int &a)
{
    cout << "常量引用" << endl;
}

int main()
{
    int a = 10;
    func(a);  // 普通引用
    func(10); // 常量引用
}
```

函数重载碰到默认参数时容易出现二义性，尽量少一起使用

```cpp
void func(int a, int b = 10)
{
}

void func(int a)
{
}

// func(10);  调用不明确
```

4. 类和对象

C++ 面向对象的三大特性：封装、继承、多态

① 封装

属性和行为作为一个整体，用来描述生活中的事物

属性：成员变量

行为：成员函数

```cpp
class Student
{
public:
    string m_Name;
    int m_Id;

    void showStudent()
    {
        cout << "姓名：" << m_Name << " 学号：" << m_Id << endl;
    }
};

int main()
{
    Student s1;
    s1.m_Name = "张三";
    s1.m_Id = 1;
    s1.showStudent();
}
```

② 访问权限

`public`：公共权限，类内可以访问，类外也可以访问

`protected`：保护权限，类内可以访问，类外不可以访问

`private`：私有权限，类内可以访问，类外不可以访问

```cpp
class Person
{
public:
    string m_Name;

protected:
    string m_Car;

private:
    int m_Password;
};
```

`class` 默认权限是 `private`

`struct` 默认权限是 `public`

③ 成员属性私有化

可以自己控制读写权限，对于写权限可以检测数据是否合法

```cpp
class Person
{
public:
    void setName(string name)
    {
        m_Name = name;
    }

    string getName()
    {
        return m_Name;
    }

    void setAge(int age)
    {
        if (age < 0 || age > 150)
        {
            cout << "年龄输入有误" << endl;
            return;
        }
        m_Age = age;
    }

    int getAge()
    {
        return m_Age;
    }

private:
    string m_Name;
    int m_Age;
};
```

④ 设计案例：立方体类

```cpp
class Cube
{
public:
    void setL(int l)
    {
        m_L = l;
    }

    void setW(int w)
    {
        m_W = w;
    }

    void setH(int h)
    {
        m_H = h;
    }

    int calculateS()
    {
        return 2 * (m_L * m_W + m_L * m_H + m_W * m_H);
    }

    int calculateV()
    {
        return m_L * m_W * m_H;
    }

    bool isSameByClass(Cube &c)
    {
        return m_L == c.m_L && m_W == c.m_W && m_H == c.m_H;
    }

private:
    int m_L;
    int m_W;
    int m_H;
};
```

⑤ 设计案例：点和圆的关系

点在圆内、圆上、圆外可以比较点到圆心的距离平方和半径平方

$$
(x_1 - x_2)^2 + (y_1 - y_2)^2 \quad \text{和} \quad r^2
$$

```cpp
class Point
{
public:
    void setX(int x)
    {
        m_X = x;
    }

    void setY(int y)
    {
        m_Y = y;
    }

    int getX()
    {
        return m_X;
    }

    int getY()
    {
        return m_Y;
    }

private:
    int m_X;
    int m_Y;
};

class Circle
{
public:
    void setCenter(Point center)
    {
        m_Center = center;
    }

    void setR(int r)
    {
        m_R = r;
    }

    Point getCenter()
    {
        return m_Center;
    }

    int getR()
    {
        return m_R;
    }

private:
    Point m_Center;
    int m_R;
};
```

```cpp
void isInCircle(Circle &c, Point &p)
{
    int distance = (c.getCenter().getX() - p.getX()) * (c.getCenter().getX() - p.getX())
                 + (c.getCenter().getY() - p.getY()) * (c.getCenter().getY() - p.getY());
    int rDistance = c.getR() * c.getR();

    if (distance == rDistance)
    {
        cout << "点在圆上" << endl;
    }
    else if (distance > rDistance)
    {
        cout << "点在圆外" << endl;
    }
    else
    {
        cout << "点在圆内" << endl;
    }
}
```

5. 对象特性

① 构造函数和析构函数

构造函数：创建对象时自动调用，用于初始化

析构函数：对象销毁前自动调用，用于清理

```cpp
class Person
{
public:
    Person()
    {
        cout << "构造函数调用" << endl;
    }

    ~Person()
    {
        cout << "析构函数调用" << endl;
    }
};
```

构造函数特点

1. 没有返回值，也不用写 `void`

2. 函数名称和类名相同

3. 可以有参数，因此可以发生重载

4. 程序在调用对象时会自动调用构造函数，无须手动调用，而且只调用一次

析构函数特点

1. 没有返回值，也不用写 `void`

2. 函数名称和类名相同，在名称前加 `~`

3. 不可以有参数，因此不可以发生重载

4. 程序在对象销毁前会自动调用析构函数，无须手动调用，而且只调用一次

② 构造函数的分类及调用

按参数分：有参构造、无参构造

按类型分：普通构造、拷贝构造

```cpp
class Person
{
public:
    Person()
    {
        cout << "无参构造函数" << endl;
    }

    Person(int a)
    {
        m_Age = a;
        cout << "有参构造函数" << endl;
    }

    Person(const Person &p)
    {
        m_Age = p.m_Age;
        cout << "拷贝构造函数" << endl;
    }

    int m_Age;
};

void test01()
{
    Person p1;
    Person p2(10);
    Person p3(p2);
}
```

③ 拷贝构造函数调用时机

1. 使用一个已经创建完毕的对象来初始化一个新对象

```cpp
Person p1(20);
Person p2(p1);
```

2. 值传递的方式给函数参数传值

```cpp
void doWork(Person p)
{
}
```

3. 值方式返回局部对象

```cpp
Person doWork2()
{
    Person p1;
    return p1;
}
```

④ 构造函数调用规则

C++ 编译器至少给一个类添加 3 个函数

1. 默认构造函数

2. 默认析构函数

3. 默认拷贝构造函数，对属性进行值拷贝

如果用户定义有参构造函数，C++ 不再提供默认无参构造，但是会提供默认拷贝构造

如果用户定义拷贝构造函数，C++ 不再提供其他构造函数

⑤ 深拷贝与浅拷贝

浅拷贝：简单的赋值拷贝操作

深拷贝：在堆区重新申请空间，进行拷贝操作

有指针成员时，浅拷贝会让两个对象指向同一块堆区内存，析构时容易重复释放

```cpp
class Person
{
public:
    Person(int age)
    {
        m_Age = new int(age);
    }

    Person(const Person &p)
    {
        m_Age = new int(*p.m_Age);
    }

    ~Person()
    {
        if (m_Age != NULL)
        {
            delete m_Age;
            m_Age = NULL;
        }
    }

    int *m_Age;
};
```

⑥ 初始化列表

作用：初始化属性

```cpp
class Person
{
public:
    Person(int a, int b, int c) : m_A(a), m_B(b), m_C(c)
    {
    }

    int m_A;
    int m_B;
    int m_C;
};
```

⑦ 类对象作为类成员

类中的成员可以是另一个类的对象，该成员叫对象成员

构造顺序：先构造成员对象，再构造本类对象

析构顺序：和构造顺序相反

```cpp
class Phone
{
public:
    Phone(string name)
    {
        m_PhoneName = name;
    }

    string m_PhoneName;
};

class Person
{
public:
    Person(string name, string phoneName) : m_Name(name), m_Phone(phoneName)
    {
    }

    string m_Name;
    Phone m_Phone;
};
```

⑧ 静态成员

静态成员变量

1. 所有对象共享同一份数据

2. 在编译阶段分配内存

3. 类内声明，类外初始化

```cpp
class Person
{
public:
    static int m_A;
    int m_B;
};

int Person::m_A = 100;

int main()
{
    Person p;
    cout << p.m_A << endl;
    cout << Person::m_A << endl;
}
```

静态成员函数

1. 所有对象共享同一个函数

2. 静态成员函数只能访问静态成员变量

```cpp
class Person
{
public:
    static int m_A;
    int m_B;

    static void func()
    {
        m_A = 100;
        // m_B = 100;  错误
    }
};

int Person::m_A = 0;
```

⑨ 成员变量和成员函数分开存储

只有非静态成员变量属于类对象上

静态成员变量、非静态成员函数、静态成员函数都不属于类对象上

```cpp
class Person
{
public:
    int m_A;
    static int m_B;

    void func()
    {
    }

    static void sfunc()
    {
    }
};

cout << sizeof(Person) << endl;
```

⑩ this 指针

每一个非静态成员函数只会诞生一份函数实例，多个同类型对象会共用同一块代码

`this` 指针隐含在每一个非静态成员函数内，指向被调用的成员函数所属对象

用途

1. 当形参和成员变量同名时，可以用 `this` 指针区分

2. 在类的非静态成员函数中返回对象本身，可使用 `return *this`

```cpp
class Person
{
public:
    Person(int age)
    {
        this->m_Age = age;
    }

    Person &personAddPerson(Person &p)
    {
        this->m_Age += p.m_Age;
        return *this;
    }

    int m_Age;
};

int main()
{
    Person p1(10);
    Person p2(10);
    p2.personAddPerson(p1).personAddPerson(p1);
}
```

⑪ 空指针访问成员函数

空指针也可以调用成员函数，但成员函数中不能使用 `this` 指针指向的数据

```cpp
class Person
{
public:
    void showClassName()
    {
        cout << "Person" << endl;
    }

    void showPersonAge()
    {
        if (this == NULL)
        {
            return;
        }
        cout << m_Age << endl;
    }

    int m_Age;
};

int main()
{
    Person *p = NULL;
    p->showClassName();
    p->showPersonAge();
}
```

⑫ const 修饰成员函数

常函数：成员函数后面加 `const`，不能修改成员属性

成员属性声明时加 `mutable` 后，即使在常函数中也可以修改

常对象：声明对象前加 `const`，常对象只能调用常函数

```cpp
class Person
{
public:
    void showPerson() const
    {
        // m_A = 100;  错误
        m_B = 100;
    }

    int m_A;
    mutable int m_B;
};

int main()
{
    const Person p;
    p.showPerson();
}
```

6. 友元

友元可以让类外的函数或者类访问类中的私有成员

关键字：`friend`

① 全局函数做友元

```cpp
class Building
{
    friend void goodGay(Building *building);

public:
    Building()
    {
        m_SittingRoom = "客厅";
        m_BedRoom = "卧室";
    }

public:
    string m_SittingRoom;

private:
    string m_BedRoom;
};

void goodGay(Building *building)
{
    cout << "好基友正在访问：" << building->m_SittingRoom << endl;
    cout << "好基友正在访问：" << building->m_BedRoom << endl;
}
```

② 友元类

```cpp
class Building
{
    friend class GoodGay;

public:
    Building()
    {
        m_SittingRoom = "客厅";
        m_BedRoom = "卧室";
    }

private:
    string m_SittingRoom;
    string m_BedRoom;
};

class GoodGay
{
public:
    void visit()
    {
        Building building;
        cout << building.m_SittingRoom << endl;
        cout << building.m_BedRoom << endl;
    }
};
```

③ 成员函数做友元

```cpp
class Building;

class GoodGay
{
public:
    GoodGay();
    void visit();

    Building *building;
};

class Building
{
    friend void GoodGay::visit();

public:
    Building();

private:
    string m_BedRoom;
};

Building::Building()
{
    m_BedRoom = "卧室";
}

GoodGay::GoodGay()
{
    building = new Building;
}

void GoodGay::visit()
{
    cout << building->m_BedRoom << endl;
}
```

7. 运算符重载

对已有的运算符重新定义，赋予其另一种功能

不能改变运算符的优先级，也不能改变运算符的操作数个数

① 加号运算符重载

```cpp
class Person
{
public:
    int m_A;
    int m_B;
};

Person operator+(Person &p1, Person &p2)
{
    Person temp;
    temp.m_A = p1.m_A + p2.m_A;
    temp.m_B = p1.m_B + p2.m_B;
    return temp;
}

int main()
{
    Person p1;
    p1.m_A = 10;
    p1.m_B = 10;

    Person p2;
    p2.m_A = 10;
    p2.m_B = 10;

    Person p3 = p1 + p2;
    cout << p3.m_A << endl;
    cout << p3.m_B << endl;
}
```

也可以写成成员函数

```cpp
Person operator+(Person &p)
{
    Person temp;
    temp.m_A = this->m_A + p.m_A;
    temp.m_B = this->m_B + p.m_B;
    return temp;
}
```

② 左移运算符重载

一般使用全局函数重载左移运算符，才能在左侧输出

```cpp
class Person
{
public:
    Person(int a, int b)
    {
        m_A = a;
        m_B = b;
    }

    int m_A;
    int m_B;
};

ostream &operator<<(ostream &cout, Person &p)
{
    cout << "m_A = " << p.m_A << " m_B = " << p.m_B;
    return cout;
}

int main()
{
    Person p(10, 10);
    cout << p << endl;
}
```

返回 `ostream` 引用，可以继续链式输出

③ 递增运算符重载

前置递增返回引用，后置递增用占位参数区分

```cpp
class MyInteger
{
    friend ostream &operator<<(ostream &cout, MyInteger myint);

public:
    MyInteger()
    {
        m_Num = 0;
    }

    MyInteger &operator++()
    {
        m_Num++;
        return *this;
    }

    MyInteger operator++(int)
    {
        MyInteger temp = *this;
        m_Num++;
        return temp;
    }

private:
    int m_Num;
};

ostream &operator<<(ostream &cout, MyInteger myint)
{
    cout << myint.m_Num;
    return cout;
}

int main()
{
    MyInteger myint;
    cout << ++myint << endl;
    cout << myint++ << endl;
    cout << myint << endl;
}
```
