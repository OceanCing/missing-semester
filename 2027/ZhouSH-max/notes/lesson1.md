## 一、 Linux 基础
1. **操作系统与发行版**：Linux 指内核， Ubuntu 是包含了系统工具和默认配置的发行版。团队选择 Ubuntu 是因为对 ROS 机器人和控制程序的兼容性极好。
2. **开发模式**：机器人开发中，我们通常用开发电脑通过 SSH/网络连接 Ubuntu Server，运行 ROS 节点或控制程序。
3. **目录结构**：
   - `/` 是根目录，`/home` 存用户文件，`/etc` 存配置，`/usr` 存程序，`/dev` 存设备。
   - **路径**：绝对路径从 `/` 开始，相对路径从当前位置开始。`~` 是家目录，`.` 是当前，`..` 是上一级。

## 二、 Shell 与终端命令
1. **命令结构**：`命令 [选项] [参数]`（例如 `ls -la ~/projects`）。
2. **文件操作**：
   - `pwd` 查看当前目录；`cd` 切换目录。
   - `mkdir -p` 创建目录；`touch` 新建文件。
   - `cp` 复制；`mv` 移动/重命名；`rm` 删除（不进回收站，慎用）。
   - `cat` 查看文件内容。
3. **Shell的常用组合**：
   - **变量**：`name="RM"`，用 `$name` 引用。
   - **重定向**：`>` 覆盖写入，`>>` 追加写入。
   - **管道（重点）**：`|`，把前一个命令的输出交给下一个程，即上一个命令的输出是下一条命令的输入。
   - **条件连接**：`&&`，前一条成功才执行后一条。
4. **帮助与技巧**：遇到陌生命令时可以用`ls --help` 或 `man ls` 查手册；用 `Tab` 补全路径；用上下方向键看历史命令。

## 三、 Vim 编辑器
1. **核心理念**：有模式的编辑器。
2. **三种模式**：
   - 普通模式（默认）：移动、删除、复制。
   - 插入模式（按 `i`）：输入文本。
   - 命令行模式（按 `:`）：保存、退出。
3. **常用快捷键**：
   - `dd` 删除当前行(前面加数字代表往后删除几行，例如10dd代表往后删除10行）；`yy` 复制；`p` 粘贴；`u` 撤销。
   - 保存退出：`:wq`；放弃修改退出：`:q!`。

## 四、 Git 与 GitHub 协作
1. **核心概念**：Git 是本地版本控制，GitHub 是远程托管与协作平台。
2. **四个核心区域的作用**

| 区域 | 作用 |
| :--- | :--- |
| **工作区** (Workspace) | 正在编辑的文件 |
| **暂存区** (Staging Area) | 本次提交的内容清单 |
| **本地仓库** (Local Repo) | 已记录的提交历史 |
| **远程仓库** (Remote Repo) | 远程保存的提交历史（如 GitHub） |

3. **工作流程**：工作区 -> 暂存区 -> 本地仓库 -> 远程仓库 。
   **对应命令**
  `-- (git add)` --> **暂存区** 
  `-- (git commit)` --> **本地仓库** 
  `-- (git push)` --> **GitHub 远程仓库**
4. **首次配置**：
   - 提交作者信息：`git config --global user.name/user.email`。
   - SSH 认证：用 `ssh-keygen` 生成密钥，把 `.pub` 公钥传到 GitHub，实现免密访问。

5. **分支与 PR（团队协作）**：
   - 分支的作用：让同一仓库中的开发互不打扰，记录每一步修改。
   - 开发新功能或做作业，先创建分支：`git switch -c feature/xxx`。
   - 团队 PR 流程：Fork 团队仓库 -> Clone 到本地 -> 修改并 Commit -> Push 到个人 Fork -> 在 GitHub 网页发起 Pull Request 等待 Review。

## 五、Git 常用命令速查

#### 1. 获取与查看
- `git clone <仓库地址>`：下载远程仓库及提交历史到本地。
- `git status`：查看当前分支和文件状态（最常用的命令，看文件是红的还是绿的）。
- `git diff`：查看尚未暂存的修改内容。
- `git log --oneline`：用简短的一行格式查看提交历史。

#### 2. 分支管理与提交（核心工作流）
- `git switch -c feature/xxx`：创建并切换到新的功能分支。
- `git add <文件名>`：将指定文件修改加入到暂存区。
- `git commit -m "提交信息"`：记录一次本地提交（英文大写开头带句号）。
- `git push -u origin feature/xxx`：推送到远程仓库，并建立跟踪关系。
- `git switch main`：切回主分支。
- `git pull`：获取并整合当前分支的远程最新更新。
