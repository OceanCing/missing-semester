Lesson 1 学习笔记

1）

`pwd`：查看当前目录
`ls`：查看目录下的文件
`cd`：切换目录
`mkdir`：创建文件夹
`touch`：创建文件
`cat`：查看文件内容
`cp`：复制文件
`mv`：移动文件

2）

Shell部分

`|`：把前一个命令的输出交给下一个命令
`>`：将输出写入文件，覆盖原来的内容
`>>`：将输出追加到末尾


3）Vim

文本编辑器。

`i`：进入编辑`Esc`：退出编辑
`:w`：保存
`:q`：退出
`:wq`：保存+退出

##不熟

4）


`git status`：查看文件状态
`git add`：添加文件
`git commit`：提交
 `git branch`：查看分支
`git switch`：切换
`git push`：推送远程仓库

Fork 是复制别人的仓库到自己的 GitHub 账号，Clone 是把仓库下载到本地。Pull Request（PR）则是向原仓库提交修改请求，让别人检查自己的代码。
