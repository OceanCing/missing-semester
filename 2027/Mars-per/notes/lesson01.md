## 1.4 Linux的目录从/开始
  *路径大小写敏感；～是当前目录的家目录，.是当前目录，..是上一级*

| 目录       | 作用                   |
|------------|------------------------|
| /          | 根目录，所有路径的起点 |
| /home/user | 用户文件               |
| /etc       | 系统配置               |
| /usr       | 程序与库               |
| /var       | 日志等可变数据         |
| /dev       | 设备文件               |

**绝对路径：从  /  开始： /home/user/example**
**相对路径：从当前目录开始：./hello.txt**
**home目录中的example：~/example**

# 2.shell&Vim

## 2.1 Shell
### 2.1.1 终端、shell与命令

   *在终端输入命令、由shell解释，再交给程序执行*
| Terminal终端     | 输入输出界面                 |
|------------------|------------------------------|
| Shell（Bash/Zsh）| 解释命令、展开路径、组织执行 |
|------------------|------------------------------|
| 程序/系统        | ls查看文件，git管理版本      |
1.创建目录  `～/example`
2.新建文件  `hello.txt`
3.编辑内容  `Vim`
4.记录修改  `Git`

### 2.1.2 Shell命令的结构

     **命令【选项】【参数】**
|`ls`   |`-la`     |`~/projects`  |
|-------|----------|--------------|
| 命令  | 选项     | 参数         |
|做什么 | 怎么执行 | 操作哪个对象 |

### 2.1.3 文件与目录操作

| 命令    | 作用         |
|---------|--------------|
|`pwd`    | 显示当前目录 |
|`ls`     | 列出目标内容 |
|`cd 目录` | 进入指定目标 |
|`cd ..`   | 返回上一级   |
|`cd ~`   | 返回家目录   |
  *相对路径以当前位置为起点*

| 命令         | 作用                 | 示例                     |
|--------------|----------------------|--------------------------|
| `mkdir -p`   | 创建目录并补齐父目录 | `mkdir -p demo/a`        |
| `touch`      | 创建空文件           | `touch hello.txt`        |
| `cp`         | 复制文件             | `cp hello.txt copy.txt`  |
| `mv`         | 移动或重命名         | `mv copy.txt backup.txt` |
| `rm`         | 删除文件             | `rm backup.txt`          |
| `cat/less`   | 查看文件/分页查看    | `cat hello.txt`          |
> 注意：rm通常不进回收站，删除前先确认路径和文件名。

### 2.1.4 Shell的四种常见组合

| 变量    | `name="RM" /  echo "$name"`  | 保存一个值，再通过变量引用它 |
|---------|------------------------------|------------------------------|
| 重定向  | `echo "hello" > hello.txt`   | >覆盖写入；>>追加到文件末尾  |
|---------|------------------------------|------------------------------|
| 管道    | `ls -la|grep txt`            | 将输出交给下一个程序         |
|---------|------------------------------|------------------------------|
|条件连接 | `mkdir -p demo && cd demo`   | 前一条成功后，再执行下一条   |

### 2.1.5 陌生命令的帮助入口

- `ls --help`  快速查看选项和用法
- `man ls`  打开手册，按q退出
- `Tab`  补全命令或路径

# 3.Git&GitHub

## 3.1 Git与GitHub的分工

- Git：本地版本控制   记录每次提交，比较修改、查看历史，为新功能创建分支
- GitHub：远程托管与协作   托管Git仓库，通过PR讨论和评审，合并团队认可的修改

## 3.2 Git的四个位置
  *先选择本次要记录的修改，再提交到本地，最后推送到远程*

1.工作区：正在编辑的文件
2.暂存区：本次提交的内容清单
3.本地仓库：已记录的提交历史
4.GitHub远程仓库：远程保存的提交历史
**commit只记录到本地仓库；push才把提交发送到远程**

## 3.3 首次使用Git：提交作者
  *姓名和邮箱会写入提交记录*

- `git config --global user.name "your name"`
- `git config --global user.email "you@example.com`

- **提交作者信息** 回答“这次修改由谁提交”
- **SSH认证**  证明你有权访问远程仓库

## 3.4 SSH密钥：公钥和私钥

- `ssh-keygen -t ed25519 -C "your@example.com"`
- `cat ~/.ssh/id_ed25519.pub`
- 公钥.pub：`id_ed25519.pub`  复制到GitHub的SSh设置
- 私钥: ` cat ~/.ssh/id_ed25519.pub` 不上传、不截图、不分享

## 3.6 Git常见命令：获取与查看

| 命令                    | 作用                   |
|-------------------------|------------------------|
| `git clone＜仓库地址＞` | 下载仓库及提交历史     |
| `git status`            | 查看当前分支和文件状态 |
| `git diff`              | 查看尚未暂存的修改     |
| `git log--oneline`      | 用简短格式查看提交历史 |

## 3.7 Git常见命令：分支与提交

| 命令                              | 作用                         |
|-----------------------------------|------------------------------|
| `git switch -c feature/hello`     | 创建并切换到功能分支         |
| `git add hello.txt`               | 暂存指定文件                 |
| `git commit -m "Add greeting"`    | 记录一次本地提交             |
| `git push -u origin feature/hello`| 推送并建立跟踪关系           |
| `git switch main`                 | 切回主分支                   | 
| `git pull`                        | 获取并整合当前分支的远程更新 |

## 3.8 分支：为新功能保留独立开发线

- main保持稳定，feature/hello承载本次修改，评审后再修改
- 分支让同一仓库中的开发互不打扰，提交点记录每一次修改

## 3.9 团队PR工作流
  *默认使用Fork协作：远程复制仓库，本地开发，再向团队发起合并请求*
