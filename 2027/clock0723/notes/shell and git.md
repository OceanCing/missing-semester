# 第一节课笔记
## 1. Linux
Ubuntu就属于linux，用于机器人开发,可以通过ssh远程控制执行节点和程序
## 2. shell命令行
在终端（ctrl+alt+T打开）中运行，格式: 命令 -选项 参数 （空格不能漏也不能多）
### 常用命令
- #### 目录相关
  - 显示当前所在目录 **pwd**
  - 进入指定目录 **cd 目录名** （./当前目录开始 ..上一级 ~/home目录开始）
  - 列出目录内的文件 **ls**
  - 创建目录，自动补齐多级父目录 **mkdir -p 目录路径**
  - 如果记得名字但忘记在哪个目录 **find -name "文件名"**
- #### 文件相关
  - 创建空文件/更新时间 **touch 文件名**
  - 复制文件 **cp 原文件名 目标文件名**
  - 移动文件/重命名文件 **mv 原文件名 目标文件名**
  - 删除文件，无回收站，谨慎操作 **rm 文件名**
  - 直接查看内容 **cat 文件名**
  - 分页查看内容 **less 文件名**
  - 带行号查看内容 **bat 文件名**
  - 从尾部查看内容 **tail -行数 文件名**
  - 从头部查看内容 **head  -行数 文件名**
  - 删除字符 **tr -d  ’要删除的字符'**
  - 替换字符 **tr '旧字符'   '新字符'**
  - 统计字数 **wc**
- #### 常用组合
  - 定义变量 **变量名="值"**，使用变量的值 **$变量名**  `系统变量$0 文件路径`
  - 重定向 **命令>>/>文件**（把命令结果覆盖文件/写入文件最后一行）`echo "hello" > hello.txt`
  - 管道，把前命令输出交给下一条命令处理 **命令1 | 命令2 （多搭配grep筛选）** `ls -la | grep txt`
  - 前一条执行成功才执行后一条命令 **命令1 && 命令2**  `mkdir -p demo && cd demo`
- #### 查询类
  - 快速查看命令帮助选项 **命令 --help**
  - 打开命令说明手册，q退出手册 **man 命令**
#### 可以给终端安装各种各样的插件，符合自己的使用和审美
## 3.vim
用于编辑文件
使用vim打开指定文件 **vim 文件名**
### 使用方法
- #### 模式切换
  - 普通模式进入命令行模式 **：**键（输入在底部）
  - 普通模式进入插入模式， **i**键
  - 退回普通模式 Esc
- #### 普通模式快捷键
  - 光标移动：左 / 下 / 上 / 右 **h j k l**
  - 删除当前整行 **dd**
  - 当前整行 **yy**
  - 粘贴复制的内容 **p**
  - 撤销上一步操作 **u**
  - 在文件内搜索指定关键词 **/关键词**
- #### 命令：
  - 保存文件 **:w**
  - 退出vim编辑器 **:q**
  - 保存文件并退出 **:wq**
  - 放弃全部修改，强制退出 **:q!**
## git和github
git:用于本地版本控制
github团队协作管理代码平台
### 前置操作
- #### 设置账号和邮箱
  1. ``` git config --global user.name "你的GitHub用户名"```
  2. ```git config --global user.email "你的GitHub注册邮箱"```
  
- #### 设置ssh
  1. ```ssh-keygen -t ed25519 -C "你的GitHub注册邮箱"```
  2. ```cat ~/.ssh/id_ed25519.pub```
  3. 复制输出
  4. 在github的设置中增加ssh
  5. ```ssh -T git@github.com```
### 团队使用流程规范
| 环节顺序 | 内容 | 对应操作 |
| ---- | ---- | ---- |
| 1 | 团队仓库 | 找到项目仓库网址 |
| 2 | 个人 Fork | GitHub网页点击fork（无git命令） |
| 3 | Clone | **git clone** git@github.com:用户名/fork仓库.git（网页可复制）<br>cd 仓库目录 |
| 4 | Feature 分支 | **git switch** -c feature/xxx 新建并切换功能分支<br>**git status** |
| 5 | 修改 / Add / Commit | **修改文件**<br>**git diff**  查看改动内容<br>**git add 文件名**<br>**git status** <br>**git commit -m "提交说明"**（大写开头带句号,在仓库目录任意一个目录运行都没有区别，和路径无关）<br>**git restore** 删除某个文件的提交<br>**git reset** 想要删除某次修改(--soft 恢复到commit之前 --mixed恢复到add之前 --hard恢复到文件修改前）<br>**git log --oneline** |
| 6 | Push | **git push** -u origin feature/xxx |
| 7 | 个人 Fork 接收提交 | GitHub网页操作 |
| 8 | 发起 PR | GitHub网页操作（标题大写） |
| 9 | Review 评审 | GitHub网页操作 |
| 10 | Merge 到团队仓库 | 网页合并后本地同步<br>**git switch main**<br>**git pull** |
