###Linux、Shell&&Shell、Git&&Github

## 一、 Linux 基础与目录结构
Linux 的目录是从根目录 `/` 开始的（注意大小写）
*   `/home/user`：用户文件（`~` 代表当前用户的家目录，.是当前目录，..是上一级）
*   `/etc`：系统配置文件
*   `/usr`：程序与库
*   `/var`：日志等可变数据
*   `/dev`：设备文件

**路径的区分**：
*   **绝对路径**：从 `/` 开始，例如 `/home/user/example`
*   **相对路径**：从当前位置开始，例如 `./hello.txt`
*   `.` 代表当前目录，`..` 代表上一级目录。

## 二、 终端、Shell 与命令
*   **Terminal (终端)**：我们输入输出的界面窗口。
*   **Shell (Bash/Zsh)**：接收终端输入的字符，负责解释命令、展开路径，并组织执行。
*   **程序 / 系统**：最终执行操作的底层，例如 `ls` 查看文件，`git` 管理版本。

### 常用文件与目录操作
| 命令 | 作用 | 示例 |
| :--- | :--- | :--- |
| `mkdir -p` | 创建目录（允许补齐父目录） | `mkdir -p ~/linux_demo` |
| `touch` | 创建空文件 / 更新时间 | `touch hello.txt` |
| `cp` | 复制文件 | `cp hello.txt hello-copy.txt` |
| `mv` | 移动或重命名 | `mv hello-copy.txt backup.txt` |
| `rm` | 删除文件 | `rm backup.txt` |
| `cat / less`| 直接查看 / 分页查看 | `cat hello.txt` |

> `rm` 删除通常不进回收站，删除前一定要先确认路径和文件名！

### Shell 的四种常用组合
1.  **变量**：保存一个值，再通过变量引用它。
    *   即 `name="RM"` 然后 `echo "$name"`
2.  **重定向**：把输出写到文件里。
    *   即 `>`：覆盖写入；`>>`：追加到文件末尾。
    *   例：`echo "hello" > hello.txt`
3.  **管道**：将前一个程序的输出，交给下一个程序处理。
    *   例：`ls -la | grep txt`
4.  **条件连接**：`&&` 表示前一条命令成功后，再执行下一条。
    *   例：`mkdir -p demo && cd demo`

## 三、 Vim 编辑器
Vim 是 Linux 下常用的文本编辑器，核心在于模式的切换。

### 1. 三种模式
*   **普通模式**：打开时的默认模式。
*   **插入模式**：按 `i` 进入，可以打字编辑。按 `Esc` 返回普通模式。
*   **命令行输入模式**：在普通模式下按 `:` 进入，用于保存或退出。

### 2. 必备按键
*   `hjkl`：分别对应左下上右移动光标。
*   `dd`：删除当前行。
*   `yy` / `p`：复制当前行 / 粘贴。
*   `u`：撤销。
*   `/word`：搜索关键词 word。

### 3. 保存与退出命令
*   `:w`：保存。
*   `:q`：退出。
*   `:wq`：保存并退出。
*   `:q!`：放弃修改并强制退出。

## 四、 Git 与 GitHub的分工
*   **Git**：本地版本控制工具。记录每次提交、比较修改、查看历史、为新功能创建分支。
*   **GitHub**：远程托管与协作。托管Git仓库，通过PR进行讨论和评审，合并团队认可的修改。

### Git 的四个位置
1.  **工作区**：正在编辑的文件。
2.  **暂存区**：本次提交的内容清单（使用 `git add` 添加）。
3.  **本地仓库**：已记录的提交历史（使用 `git commit` 提交）。
4.  **GitHub 远程仓库**：远程保存的提交历史（使用 `git push` 推送）。

> `commit` 只记录到本地仓库；`push` 才把提交发送到远程。
