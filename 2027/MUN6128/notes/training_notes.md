# Training Notes: Linux, Vim, Shell, Git and GitHub

## 1. Linux

Linux is an operating system widely used in software development.

Common commands:

- `pwd`: Print the current working directory.
- `ls -la`: List files, including hidden files.
- `cd`: Change the current directory.
- `mkdir`: Create a directory.
- `cp`: Copy files.
- `mv`: Move or rename files.
- `cat`: Display file contents.

## 2. Vim

Vim is a text editor that can be used in a terminal.

- `i`: Enter Insert mode.
- `Esc`: Return to Normal mode.
- `:w`: Save the file.
- `:q`: Quit.
- `:wq`: Save and quit.
- `:q!`: Quit without saving.

## 3. Shell

A shell interprets commands and supports task automation.

Examples:

    echo "Hello, Linux"
    date
    whoami
    history

Useful operators:

- `>` redirects output to a file and overwrites it.
- `>>` appends output to a file.
- `|` passes output between commands.
- `&&` runs the next command if the previous command succeeds.

## 4. Git

Git is a distributed version control system.

Common commands:

- `git status`: Check the working tree.
- `git add`: Stage changes.
- `git commit`: Save a snapshot.
- `git log --oneline`: View commit history.
- `git diff`: Inspect changes.

Branches allow developers to work independently.

## 5. GitHub

GitHub hosts Git repositories and supports collaboration.

- A repository stores project files and version history.
- Fork creates a personal copy of a repository.
- A branch isolates a line of development.
- A Pull Request proposes changes for review.
- Code review comments help contributors improve their work.

Typical workflow:

1. Fork the repository.
2. Clone the fork.
3. Create a development branch.
4. Edit and test files.
5. Commit and push changes.
6. Open a Pull Request.
7. Address review comments.

## 6. Reflection

In this training, I practiced Linux commands, learned basic Vim operations, explored shell scripting, and learned how Git branches and Pull Requests support collaboration.
